# Tasks

Новая логика идёт строго по TDD, по одному шагу:

- красный тест: запустить и увидеть, что он падает по ожидаемой причине;
- минимальный код до зелёного;
- рефакторинг без изменения поведения.

Расчёты проверяются на маленьких эталонных наборах с заранее посчитанными итогами: учебное исполнение, дневной стоп,
совпадение с условиями. Тесты и локальные запуски ходят только в подменённый транспорт, `FakeExchange` или заглушку
Bybit; реальных ордеров нет. Перед добавлением типа или папки в `backend/` свериться с `docs/conventions.md`.

- [x] 1.8 Проверка учебного входа `Services/IdeaAutos/PaperEntry.Check`. Проверяет: цену за стопом или целью, R:R ниже

## 3. Сканер

- [x] 3.1 `LiveIdeas` каждую минуту читает включённые автоматы. Для каждой новой идеи минуты с полной парой он:
  - считает `IdeaView.Of`, читая корзины, только если идея родилась и автомат включён;
  - сверяет идею с условиями;
  - для «Без денег» проверяет учебный вход и создаёт учебную сделку или отказ;
  - для «С деньгами» пишет заявку с аккаунтом, суммой, минимальным R:R и местом автомата на эту минуту.

  Готово, когда `LiveIdeasTests` проверяют: выключенный автомат ничего не пишет; прогрев не даёт заявок; учебная сделка
  записана; у неподходящей идеи нет отказа.
- [x] 3.2 Шаг открытых учебных сделок по минутам пары от `stepped_until`. Плюс догонка при прогреве по памяти и по
  хранимым минутам, если пропуск длиннее памяти. Готово, когда юнит-тест «Стоп, пока сканер лежал» и тест пары с
  пропуском (учебная не шагает до догрузки) зелёные.
- [x] 3.3 Раз в час, рядом с чисткой закрытых идей: удалить отказы старше 7 дней и перевести не взятые Worker'ом

  чистки, а сбой одной пишется в лог и не мешает идеям минуты.
- [x] 3.4 Интеграционный тест на `ScannerHost` с `FakeBybitSocketServer`: учебный автомат на сетапе засеянного
