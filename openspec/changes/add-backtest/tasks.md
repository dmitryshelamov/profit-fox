# Tasks

Новая логика — строго red → green → refactor (см. `CLAUDE.md`): сначала падающий тест, потом минимальный код. Каждая
задача закрыта, только когда build, тесты и `dotnet format --verify-no-changes` проходят. Группы 2–3, 4–5 и 6–8 можно
выпустить отдельными PR одной ветки (design, Risks).
