# Spec Delta

## MODIFIED Requirements

### Requirement: Свеча таймфрейма из минут

Свеча таймфрейма SHALL собираться из закрытых минут своего окна UTC: `open` первой минуты, `close` последней, наибольший
`high`, наименьший `low`, суммы объёма и оборота. Минута без сделок в окне не участвует: ни та, которой лента не
прислала, ни та, что пришла с объёмом `0`. Пара, у которой в окне нет ни одной минуты со сделками, свечи не получает, и
её графы на этом окне не пересчитываются. Проход открытой идеи по минутам MUST NOT брать минуту с объёмом `0`. Для
правил «Момент закрытия свечи» и «Закрытие свечи при догоне» минута с объёмом `0` остаётся минутой ленты.

#### Scenario: Свеча 5m из пяти минут

- **WHEN** у пары закрыты минуты с `10:00` по `10:04`
- **THEN** свеча `5m`, открытая в `10:00`, несёт `open` минуты `10:00`, `close` минуты `10:04` и сумму их объёмов

#### Scenario: Минута без сделок

- **WHEN** в окне `10:00–10:05` у пары нет минуты `10:02`
- **THEN** свеча `5m` собрана из четырёх минут

#### Scenario: Окно без сделок

- **WHEN** в окне `10:00–10:05` у пары нет ни одной минуты
- **THEN** свечи `5m` с открытием `10:00` у пары нет

#### Scenario: Минута с нулевым объёмом

- **WHEN** в окне `10:00–10:05` минута `10:02` пришла с объёмом `0`, а остальные четыре — со сделками
- **THEN** свеча `5m` собрана из четырёх минут со сделками

#### Scenario: Окно из минут с нулевым объёмом

- **WHEN** все пять минут окна `10:00–10:05` пришли с объёмом `0`
- **THEN** свечи `5m` с открытием `10:00` у пары нет, и её графы на этом окне не пересчитываются

#### Scenario: Нулевая минута закрывает свечу

- **WHEN** часы показывают `12:00:15`, и из минут `11:59` лента прислала одну — с объёмом `0`
- **THEN** свечи с закрытием `12:00` считаются закрытыми
