# Spec Delta

## ADDED Requirements

### Requirement: Элемент списка бэктестов бота

Каждый элемент списка бэктестов бота SHALL содержать период, значения и диапазоны параметров, статус, причину ошибки,
прогресс и отметку «бот изменился».

#### Scenario: Диапазоны и ошибка в списке

- **WHEN** бэктест задал `fast` диапазоном `5`, `15`, `5` и завершился `Failed` с причиной загрузки свечей
- **THEN** элемент списка содержит диапазон `fast`, статус `Failed` и эту причину

#### Scenario: Бот изменился в списке

- **WHEN** после бэктеста `A` стратегию бота сохранили с изменённым графом, а бэктест `B` создан после этого
- **THEN** список бэктестов бота отмечает «бот изменился» у `A` и не отмечает у `B`
