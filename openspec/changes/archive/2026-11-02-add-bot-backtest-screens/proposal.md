# Proposal

## Why

Боты и бэктесты есть в API с изменения 2, но пользоваться ими можно только через Swagger. Чтобы создать бота,
запустить сетку из сотен комбинаций и выбрать лучшую, нужно вручную собирать JSON, раз за разом опрашивать статус и
читать метрики из ответов. После визуального редактора (изменение 3) это следующий шаг роадмапа: путь «стратегия →
бот → бэктест → выбор комбинации» целиком в интерфейсе. Без него к ключам биржи и живым ботам (изменения 4 и 5)
переходить рано.

## What Changes

- Раздел «Боты» во фронтенде (макеты согласованы в Penpot, страница «Макеты ботов и бэктестов»):
  - список ботов: стратегия, инструмент, интервал, баланс, статус последнего бэктеста;
  - создание, правка и удаление бота. Поля параметров строятся из объявлений стратегии. Символ подсказывается
    поиском инструментов биржи, у баланса подписана валюта котировки, ошибки проверки показываются на полях. Бота
    можно создать и из списка стратегий;
  - страница бота: значения параметров и список бэктестов со статусом, прогрессом, причиной ошибки и отметкой «бот
    изменился».
- Бэктесты:
  - форма: период (по умолчанию 30 дней до последней закрытой свечи), значение или диапазон для каждого параметра со
    счётчиком комбинаций, свёрнутые настройки симуляции;
  - страница бэктеста: этапы, прогресс, скорость, отмена; таблица результатов с сортировкой по метрике и страницами.
    Пока бэктест не завершён, страница опрашивает его раз в 2 секунды;
  - детали результата: метрики, общий график свечей и капитала за весь период с метками входов и выходов, таблицы
    сделок и исполнений.
- Сравнение: до шести результатов из любых бэктестов, набор в адресе страницы `/compare` и во вкладке браузера. На
  странице результаты стоят колонками, кривые капитала наложены на один график.
- Бэкенд:
  - поиск инструментов биржи по категории и запросу, `GET /api/market-data/instruments`;
  - чтение одного результата бэктеста по номеру комбинации, `GET /api/backtests/{id}/results/{combination}`;
  - точка кривой капитала в деталях результата дополнительно содержит время начала и OHLC своей группы свечей;
  - элемент списка ботов дополнительно содержит баланс и последний бэктест; элемент списка бэктестов бота — значения
    и диапазоны параметров, причину ошибки и отметку «бот изменился»;
  - адрес REST API Bybit задаётся настройкой; без неё используется живой Bybit.
- Сквозные тесты проходят весь путь «бот → бэктест → результаты → детали → сравнение» на настоящих API и Worker'е
  против локальной заглушки Bybit с детерминированными свечами.

Вне изменения: экран загрузок свечей, просмотр версий стратегии, ключи биржи, живая торговля, тепловая карта метрики
по двум параметрам (идея на будущее), режимы поиска кроме полного перебора, HTTPS и авторизация, деплой на production.

## Capabilities

### New Capabilities

- `bot-interface`: веб-интерфейс ботов: список, создание, правка и удаление бота, подсказки символа, страница бота
  со списком его бэктестов.
- `backtest-interface`: веб-интерфейс бэктестов: форма запуска, ход расчёта и отмена, таблица результатов, детали
  результата с графиком и сравнение результатов.
- `instrument-search`: поиск инструментов биржи по категории рынка и части символа или монеты.

### Modified Capabilities

- `bot-management`: список ботов дополнительно содержит баланс и последний бэктест каждого бота.
- `backtest-runs`: список бэктестов бота дополнительно содержит значения и диапазоны параметров, причину ошибки и
  отметку «бот изменился».
- `backtest-results`: точка кривой капитала дополнительно содержит время начала и OHLC своей группы свечей; чтение
  одного результата по номеру комбинации.

## Impact

- `frontend/`: новые страницы `bots`, `bot-editor`, `bot`, `backtest-setup`, `backtest`, `backtest-result`,
  `compare`; новые модули `bots`, `backtests`, `market-data`, `market-chart`, `comparison`; пункт «Боты» в шапке и
  панель сравнения в `AppShell`; действие «Создать бота» в списке стратегий. Новая зависимость `lightweight-charts`.
  `generated/schema.d.ts` перегенерируется.
- `ProfitFox.Application`: запрос поиска инструментов и порт к бирже для списка инструментов; списки ботов и
  бэктестов читают дополнительные данные.
- `ProfitFox.Domain`: группы кривой капитала в `DetailsObserver` собирают OHLC свечей.
- `ProfitFox.Infrastructure`: список инструментов Bybit с коротким кэшем в памяти; настройка `Bybit:RestAddress`.
- `ProfitFox.Presentation`: `GET /api/market-data/instruments`, `GET /api/backtests/{id}/results/{combination}`, новые поля в `BotSummaryResponse`,
  `BacktestSummaryResponse` и `EquityPointResponse`. Поля только добавляются, существующие не меняются.
- Сквозные тесты: `frontend/e2e/bybit-stub.ts`; в `playwright.config.ts` добавляются заглушка Bybit и Worker.
- Миграций нет. Production-сервер не затрагивается.
