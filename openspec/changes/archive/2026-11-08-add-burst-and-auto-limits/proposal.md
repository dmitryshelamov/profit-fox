# Proposal

## Why

Автомат берёт идеи минуты в порядке их рождения, пока хватает бюджета, и за одну минуту движения набирает пачку
однонаправленных сделок по десяткам альтов: на проде учебный автомат `paper-test` открывал до 22 лонгов за минуту и
101 сделку за час. Это одна ставка на рынок, разложенная по тикерам, и журнал такого автомата состоит из кластеров, а не
из независимых сделок. Анализ прода 2026-11-08 показал ту же беду у статистики: лучшая корзина оказалась одной неделей.
Нужны три вещи: признак «всплеск», чтобы калибровка проверила, ведут ли себя идеи рыночного движения иначе; отбор
лучших идей минуты вместо первых попавшихся; лимиты автомата на сторону, чтобы учебный журнал мерил честно, а денежный
автомат не брал один риск двадцать раз.

## What Changes

- Четвёртый признак рынка «всплеск»: число разных пар с сигналом той же стороны на том же ТФ в ту же минуту, порог по
  ТФ (5m 60, 15m 25, 1h 8, 4h 4 пары, около 90-го процентиля прода). У живой идеи число хранится при рождении; у
  сигналов прогона считается при чтении из самих сигналов, поэтому версия правил не меняется и прогона нет. Уровень
  признаков становится одним из 16 сочетаний; калибровка получает строки «всплеск · есть / нет»; идеи, сделки и журнал
  получают чип «⚡ всплеск»; автомат — условие «любой / только с / только без».
- Порядок идей минуты у автомата: по обещанному матожиданию корзины, затем по чистому R:R, идеи без корзины последними;
  заявки автомата с деньгами уходят Worker'у в этом порядке.
- Два лимита автомата, оба по умолчанию «без лимита»: «новых сделок одной стороны за минуту» и «открытых сделок одной
  стороны». Идеи сверх лимита автомат не берёт и пишет один отказ на автомат, сторону и минуту с числом пропущенных идей.
- Форма и список автоматов, тело и ответ API: четвёртый переключатель признака и два поля лимитов.
- Существующие автоматы работают как раньше: признак «любой», лимитов нет.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `trade-ideas`: ADDED «Признак всплеска»; MODIFIED «Уровень признаков» (16 сочетаний), «Версия правил с признаками»
  (признак, который считается из сигналов, версии не требует).
- `trade-ideas-interface`: MODIFIED «Признаки идеи в ответах», «Чипы признаков в строке идеи», «Таблица «По признакам»
  на экране «Калибровка»» (четыре признака).
- `idea-autos`: ADDED «Порядок идей минуты», «Лимит новых сделок стороны за минуту», «Лимит открытых сделок стороны»;
  MODIFIED «Автомат» (два лимита), «Проверка автомата» (лимиты не меньше 1), «Условия автомата» (четвёртый признак),
  «Бюджет автомата при одновременных идеях» (очередь по порядку идей минуты).
- `idea-autos-interface`: MODIFIED «Форма автомата», «Признаки в теле и ответе автомата», «Условия признаков в списке
  автоматов», «Блок «Отказы автоматов»» (подробность отказа по лимиту); ADDED «Лимиты в теле и ответе автомата».
- `idea-trades-interface`: MODIFIED «Чипы признаков в строках сделок» (четвёртый чип).

## Impact

- `ProfitFox.Domain`: `IdeaFeatures` (четвёртое поле `Burst`, `BurstThreshold` по ТФ), `IdeaFeature.Burst`, `Idea` и
  `IdeaSignal` (число пар всплеска), `IdeaAutoConditions` (условие `Burst`), `IdeaAuto` (`MaxPerMinutePerSide`,
  `MaxOpenPerSide`), `IdeaTradeRefusal.MinuteLimit` / `SideLimit`, `AutoRefusals`, новая чистая функция порядка и лимитов
  идей минуты в `Services/IdeaAutos`.
- `ProfitFox.Application`: `LiveIdeas` считает число пар всплеска у идей минуты; `LiveAutos.TakeAsync` ранжирует и
  применяет лимиты; `IdeaOutcomes` получает счёт пар по минутам из хранилища; `IdeaCodes`, `IdeaAutoInput`,
  `IdeaAutoValidation`.
- `ProfitFox.Infrastructure`: миграция `202611080007` (`ideas.burst_pairs`, `idea_autos.burst`,
  `max_per_minute_per_side`, `max_open_per_side`), запрос счёта пар по минутам в `IdeaSignalRepository`, репозитории
  автоматов и идей.
- `ProfitFox.Api`: тела и ответы автоматов, ответы идей, сделок и калибровки.
- Фронт: `ideaFeatures` (четвёртый признак), форма и список автоматов, подробность отказа по лимиту, пояснение на
  «Калибровке», схема API.
- Хранилище: три колонки `idea_autos`, одна колонка `ideas`; `idea_cases` не меняется, прогона нет; статистика раз в час
  делает ещё один запрос группировки сигналов по минутам.
- Новых внешних зависимостей нет.
