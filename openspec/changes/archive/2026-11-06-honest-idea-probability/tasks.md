## 1. Домен: статистика корзины и безубыток

- [x] 1.1 `BucketStatisticsCalculator.Compute(targets, stops, expired, totalR, totalSquaredR)` (решение 1):
  - доля «Цель» среди всех случаев и Wilson по ней;
  - интервал ожидания `среднее ± 1.96 · √(дисперсия / n)` по выборочной дисперсии;
  - при N < 30 — без вероятности, её интервала и интервала ожидания.

  Готово, когда `BucketStatisticsCalculatorTests` на эталонных числах зелёные:
  - 180 / 200 / 20 дают 0.45 и интервал 40–50 %;
  - 400 случаев со средним +0.12 R и s 1.2 дают интервал +0.002…+0.238 R;
  - 12 случаев дают «мало данных».
- [x] 1.2 `BucketStatistics` (решение 2): добавить `Targets`, `Stops`, `ExpectancyLow`, `ExpectancyHigh` и свойство
  `Badge` (`IdeaBadge { Up, Flat, Down }`, `null` при «мало данных»), удалить `Baseline` и `IsAboveBaseline`.
  Готово, когда тесты видят ▲ при +0.002…+0.238, ≈ при −0.068…+0.168, ▼ при интервале ниже нуля, `null` при 12
  случаях, а `dotnet build` не находит `Baseline` в домене.
- [x] 1.3 `IdeaShares.BreakEven` (решение 4): убыток / (прибыль + убыток), `null` при прибыли ≤ 0. Готово, когда
  `IdeaSharesTests` видят 0.021089 / (0.038878 + 0.021089) у эталонной идеи и `null` при отрицательной прибыли.
