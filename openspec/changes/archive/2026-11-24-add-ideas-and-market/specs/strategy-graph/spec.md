# Spec Delta

## MODIFIED Requirements

### Requirement: Сигнал

Сигнал SHALL быть графом с одним объявленным выходом типа «событие» или логического типа, который принимает узел выхода.
Сигнал с выходом-событием говорит, когда что-то произошло; сигнал с логическим выходом — состояние, истинное, пока
условие выполнено. Граф сигнала MUST NOT содержать узлов заявок и позиции: сигнал читает только рынок.

#### Scenario: Сигнал с двумя выходами

- **WHEN** у графа сигнала объявлены выходы `entry` и `exit`
- **THEN** проверка сообщает, что у сигнала должен быть ровно один выход

#### Scenario: Выход сигнала не событие

- **WHEN** у сигнала объявлен выход `entry` числового типа
- **THEN** проверка сообщает, что выход сигнала должен быть событием или логическим значением

#### Scenario: Узел входа в сигнале

- **WHEN** в графе сигнала H0001 есть ещё узел `enter` на событии `first.event`
- **THEN** проверка сигнала сообщает об ошибке по этому узлу: сигнал не ставит заявок

#### Scenario: Сигнал-состояние

- **WHEN** у сигнала объявлен выход `holds` логического типа, и к нему подключён выход `result` узла сравнения
- **THEN** проверка сигнала проходит без ошибок

### Requirement: Узел сигнала

Узел вида `signal` SHALL ссылаться на версию сохранённого сигнала настройками `signal` — идентификатор сигнала — и
`version` — номер версии. Входы узла SHALL быть параметрами этой версии с их именами и типами. Выход узла — один:
`event` типа «событие» у сигнала с выходом-событием и `value` логического типа у сигнала с логическим выходом. Ссылка на
сигнал или версию, которых нет, MUST давать ошибку проверки по узлу. Узел сигнала MUST NOT стоять в графе сигнала.

#### Scenario: Пины по параметрам версии

- **WHEN** узел `s` ссылается на версию 1 сигнала `funding-high` с параметром `threshold` типа «число»
- **THEN** у узла `s` один вход `threshold` типа «число» и один выход `event` типа «событие»

#### Scenario: Версии нет

- **WHEN** узел `s` ссылается на версию 7 сигнала, у которого версий две
- **THEN** проверка сообщает об ошибке по узлу `s`: такой версии сигнала нет

#### Scenario: Входа нет у версии

- **WHEN** на вход `limit` узла `s` приходит провод, а у версии сигнала параметра `limit` нет
- **THEN** проверка сообщает об ошибке по входу `limit` узла `s`

#### Scenario: Узел сигнала в сигнале

- **WHEN** в графе сигнала есть узел вида `signal`
- **THEN** проверка сигнала сообщает об ошибке по этому узлу: сигнал не ссылается на другие сигналы

#### Scenario: Узел сигнала-состояния

- **WHEN** узел `b` ссылается на сигнал `btc-drop-4h` с логическим выходом, и его выход подключён ко входу узла «и»
- **THEN** у узла `b` один выход `value` логического типа, и проверка стратегии по этому проводу ошибок не даёт

#### Scenario: Состояние на вход события

- **WHEN** выход `value` узла сигнала-состояния подключён ко входу `when` узла `enter`
- **THEN** проверка сообщает об ошибке типа по этому проводу
