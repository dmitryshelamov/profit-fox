# Tasks

Расчётная логика — строго red → green → refactor, по одному шагу. Каждая новая функция проверяется на эталонном наборе с
заранее посчитанными ответами. Прод, биржу и `.env.prod*` не трогаем.

## 1. Проход сетки

- [x] 1.1 `ExitRuleGridPass.Rules`: сетка правил типа × ТФ при окне кандидата. Проверка: сценарии «Сетка «Отката» на
  4 ч» (99 правил, окно 8) и «Сетка «Уровней»» (19 сроков без цели).
- [x] 1.2 `ExitRuleGridPass.Sums`: входы и ΣR каждого правила по 6 блокам по 15 дней. Проверка: эталон согласия на
  наборе путей со всеми ветками — суммы каждого правила сетки равны суммам `ExitOutcomes.Counted` + `CaseResult.R`;
  отдельный эталон с посчитанными вручную входами и ΣR блоков.
- [x] 1.3 Детерминизм частей: ключи делятся на 8 фиксированных частей и складываются по порядку. Проверка: тест — сумма
  с итогами, у которых decimal-сложение зависит от порядка, даёт то же, что последовательный проход в порядке частей.

## 2. Лучшее правило и PBO

- [x] 2.1 `OverfittingProbability.Best`: лучшее по ожиданию на вход на выбранных блоках среди правил от 30 входов,
  при равенстве — первое по сетке; без такого — нет. Проверка: эталонная матрица из 3 правил.
- [x] 2.2 `OverfittingProbability.Of`: 20 разбиений CSCV, место r, подгонка при r / (k + 1) ≤ 1/2, разбиение меньше
  чем с двумя участниками не считается. Проверка: эталонная матрица с посчитанными вручную 20 разбиениями (сценарий
  «Подгонка в большинстве разбиений») и сценарий «Мало правил с входами».

## 3. Расчёт проверки и API

- [x] 3.1 `ExitRuleOutOfSamples.Compute`: границы частей, N правил, кандидат и лучшее правило со скученными числами
  подбора и проверки, PBO. Проверка: эталонный набор сигналов с заранее посчитанными числами (сценарии «Лучшее на
  подборе слабее на проверке» и «Мало входов на подборе»).
- [x] 3.2 Запрос `GetExitRuleOutOfSampleQuery`, действие `GET /api/ideas/exit-rules/out-of-sample`, контракт
  `ExitRuleOutOfSampleResponse`. Проверка: интеграционные тесты «Ответ проверки» и «Окно у «Цели 2R» в проверке»;
  путь в документе OpenAPI.
- [x] 3.3 Замер на синтетике 300 тыс. сигналов: ответ расчёта до 2 с. Проверка: числа в `design.md`.
