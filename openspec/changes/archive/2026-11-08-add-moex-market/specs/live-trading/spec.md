# Spec Delta

## MODIFIED Requirements

### Requirement: Запуск бота

Система SHALL запускать остановленного бота или бота в статусе «ошибка»: статус становится «запущен», бот начинает
торговать на последней версии стратегии и текущих значениях параметров, которые MUST NOT меняться до следующего
запуска. Запуск бота в другом статусе MUST отклоняться конфликтом. Запуск бота с инструментом `moex` MUST отклоняться
конфликтом «торговля на MOEX ещё не поддерживается», пока торговля на T-Invest не введена.

#### Scenario: Запуск остановленного бота

- **WHEN** у остановленного бота есть аккаунт с достаточными деньгами, и пользователь запускает его
- **THEN** бот в статусе «запущен» и выставляет ордера по своей стратегии

#### Scenario: Повторный запуск

- **WHEN** пользователь запускает уже запущенного бота
- **THEN** система отвечает конфликтом, и бот продолжает работу

#### Scenario: Правка стратегии запущенного бота

- **WHEN** бот запущен на версии стратегии `3`, и стратегию сохранили, создав версию `4`
- **THEN** бот торгует по версии `3` до остановки и следующего запуска

#### Scenario: Бот на MOEX

- **WHEN** пользователь запускает остановленного бота с инструментом `moex` / `SBER` и аккаунтом T-Invest
- **THEN** система отвечает конфликтом с причиной «торговля на MOEX ещё не поддерживается», и бот остаётся остановленным
