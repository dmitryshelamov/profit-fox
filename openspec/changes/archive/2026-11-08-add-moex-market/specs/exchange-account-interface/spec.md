# Spec Delta

## ADDED Requirements

### Requirement: Выбор счёта T-Invest в форме

При бирже T-Invest форма SHALL принимать имя и токен, по действию «Показать счета» запрашивать счета токена и показывать
их списком с номером, названием, типом и доступностью; выбрать SHALL можно только доступный счёт. Поле токена MUST
скрывать вводимые символы. После отказа сервера форма MUST очистить токен и сбросить список счетов.

#### Scenario: Счёт выбран и сохранён

- **WHEN** владелец ввёл токен, выбрал из списка брокерский счёт с полным доступом и сохраняет
- **THEN** открывается страница нового аккаунта с биржей T-Invest и номером этого счёта

#### Scenario: Недоступный счёт

- **WHEN** в списке счетов токена есть закрытый ИИС
- **THEN** его строка показывает причину и не выбирается

### Requirement: Страница аккаунта T-Invest

Страница аккаунта T-Invest SHALL показывать биржу, имя, номер счёта, токен маской без символов, категорию `moex` и
ботов аккаунта. Баланс SHALL загружаться по действию «Показать баланс» и показываться таблицей бумаг со стоимостью в
рублях, строкой рублей и общей стоимостью счёта.

#### Scenario: Баланс в рублях

- **WHEN** владелец выбирает «Показать баланс» у аккаунта T-Invest
- **THEN** страница показывает строку `RUB`, бумаги с количеством и стоимостью в рублях и общую стоимость в рублях

## MODIFIED Requirements

### Requirement: Новый аккаунт

Форма нового аккаунта SHALL начинаться с выбора биржи: Bybit или T-Invest. При бирже Bybit форма SHALL принимать имя,
API key и secret; поле secret MUST скрывать вводимые символы. Сохранённый аккаунт SHALL открываться на своей странице.
Если сервер отклоняет аккаунт, форма MUST сохранить введённые значения, кроме secret и токена, и SHALL показать каждую
ошибку у её поля. Если биржа недоступна, форма SHALL сказать об этом над кнопками.

#### Scenario: Аккаунт добавлен

- **WHEN** владелец выбирает Bybit, вводит имя, ключ, который принимает Bybit, и сохраняет
- **THEN** открывается страница нового аккаунта

#### Scenario: Ключ отклонён

- **WHEN** сервер отклоняет ключ с ошибкой по API key
- **THEN** у поля API key ошибка сервера, имя и API key на месте

#### Scenario: Смена биржи в форме

- **WHEN** владелец переключает биржу с Bybit на T-Invest
- **THEN** форма показывает поля токена и счетов вместо API key и secret

### Requirement: Страница аккаунта

Страница аккаунта Bybit SHALL показывать биржу, имя, API key целиком, secret маской без символов ключа, UID Bybit,
категории торговли и ботов, привязанных к аккаунту, со ссылками на них. Баланс SHALL загружаться только по действию
«Показать баланс» и показываться таблицей монет с общим капиталом в USD.

#### Scenario: Secret маской

- **WHEN** владелец открывает страницу аккаунта
- **THEN** на месте secret маска `••••••••`, а API key показан целиком

#### Scenario: Баланс по действию

- **WHEN** владелец выбирает «Показать баланс»
- **THEN** страница показывает монеты с балансом, их стоимость в USD и общий капитал

#### Scenario: Биржа недоступна при чтении баланса

- **WHEN** владелец выбирает «Показать баланс», а сервер отвечает «биржа недоступна»
- **THEN** страница показывает, что биржа недоступна, и остаётся рабочей

### Requirement: Список аккаунтов биржи

Интерфейс SHALL показывать список аккаунтов: биржу, имя, категории торговли и поле биржи — API key и UID для Bybit,
номер счёта для T-Invest. Из списка SHALL открываться страница аккаунта и форма нового аккаунта. Пустой список SHALL
предлагать добавить аккаунт.

#### Scenario: Аккаунт в списке

- **WHEN** среди аккаунтов есть аккаунт «Основной» с категориями `spot` и `linear`
- **THEN** его строка показывает биржу Bybit, имя, API key, UID и обе категории

#### Scenario: Аккаунт T-Invest в списке

- **WHEN** среди аккаунтов есть аккаунт T-Invest «Брокерский»
- **THEN** его строка показывает биржу T-Invest, имя, номер счёта и категорию `moex`
