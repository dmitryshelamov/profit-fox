# Spec Delta

## MODIFIED Requirements

### Requirement: Итоги на экране «Сделки»

Над таблицей закрытых сделок SHALL стоять два блока итогов журнала по фильтру: «С деньгами» и «Учебные». В каждом:
сделки по цели, по стопу, вручную и по сроку с их долями, отменённые и с ошибкой, сумма в USDT, комиссии, средний R с
интервалом, среднее время до исхода, «обещали X R → получили Y R · N» и «идеи X R → сделки Y R · N». Сравнение без
сделок SHALL показываться «—». Если по фильтру «Кто взял» один вид сделок, SHALL стоять только его блок.

#### Scenario: Итоги

- **WHEN** по фильтру 4 сделки: по цели 1, по стопу 1, вручную 1, по сроку 1, средний R +0.3
- **THEN** итоги показывают «по цели 1 (25 %) · по стопу 1 (25 %) · вручную 1 (25 %) · по сроку 1 (25 %)» и «+0.30 R»
  с интервалом

#### Scenario: Сравнивать не с чем

- **WHEN** ни у одной закрытой сделки фильтра нет обещания
- **THEN** вместо «обещали → получили» стоит «—»

#### Scenario: Только учебные

- **WHEN** владелец выбрал «Кто взял: Учебные»
- **THEN** стоит только блок «Учебные»

## ADDED Requirements

### Requirement: Статус «Закрыта по сроку» в таблице

В таблице закрытых сделок статус `closed_at_expiry` SHALL подписываться «Закрыта по сроку», с результатом в USDT и R
и временем до исхода, как у закрытых по цели и по стопу.

#### Scenario: Учебная закрылась по сроку

- **WHEN** учебная сделка закрылась по сроку идеи с результатом −0.21 R
- **THEN** в её строке «Закрыта по сроку», «−0.21 R» и время до исхода
