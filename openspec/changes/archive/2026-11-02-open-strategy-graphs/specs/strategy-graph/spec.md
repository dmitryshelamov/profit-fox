# Spec Delta

## MODIFIED Requirements

### Requirement: Раскладка на холсте

Определение SHALL хранить координаты узлов на холсте. Раскладка MAY быть неполной: узел без координат валиден, его
место выбирает редактор. Координаты MUST NOT влиять на проверку и исполнение графа.

#### Scenario: Перемещение узла

- **WHEN** пользователь сохраняет стратегию, изменив только координаты узлов
- **THEN** сохранение проходит, а исполнение стратегии на тех же событиях даёт те же команды

#### Scenario: Стратегия без координат

- **WHEN** пользователь сохраняет стратегию с пустой раскладкой
- **THEN** сохранение проходит, и чтение возвращает пустую раскладку
