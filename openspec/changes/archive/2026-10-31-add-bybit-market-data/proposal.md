# Proposal

## Why

Бэктесту и будущей live-торговле нужны исторические свечи той же биржи, на которой будет вестись торговля, — Bybit.
Сейчас в решении нет ни источника данных, ни хранилища, поэтому ни одну стратегию нельзя проверить на реальной истории.
Загрузка данных — первый шаг, на котором строятся остальные фичи.

## What Changes

- Загрузка исторических свечей Bybit по запросу: пользователь указывает инструмент (категория `spot` или `linear` +
  символ), интервал Bybit и период `[from, to)`; загрузка выполняется в фоне как задача загрузки со статусом.
- Сохраняются только закрытые свечи; повторная загрузка того же периода идемпотентна — дубликатов не появляется.
- Символ проверяется на бирже до создания задачи; неизвестный символ или некорректные параметры отклоняются сразу.
- Чтение сохранённых свечей через HTTP API для проверки результата и будущих потребителей.
- Первое хранилище проекта: PostgreSQL с расширением TimescaleDB (свечи — hypertable), схема через миграции.
- Локальный `docker-compose` с TimescaleDB для разработки.
- Удаление шаблонного кода скаффолда (`WeatherForecast`, `UnitTest1`, `Class1`).

Вне рамок изменения: фоновая автоактуализация свечей, история funding, метаданные инструментов (tick size, lot size),
агрегация собственных таймфреймов, другие биржи, авторизация API, развёртывание на production-сервер.

## Capabilities

### New Capabilities

- `market-data-import`: загрузка исторических свечей с Bybit по запросу — задачи загрузки, их жизненный цикл, валидация
  параметров, правила сохранения (только закрытые свечи, идемпотентность).
- `market-data-query`: чтение сохранённых свечей инструмента за период.

## Impact

- **Код:** все четыре слоя `backend/src` (`Domain`, `Application`, `Infrastructure`, `Presentation`) и оба тестовых
  проекта получают первую предметную логику; шаблонный код удаляется.
- **API:** новые эндпоинты под `/api/market-data/` (создание и статус задачи загрузки, чтение свечей).
- **Внешние зависимости:** публичный REST API Bybit v5 (`api.bybit.com`, без ключа, только рыночные данные — ордера не
  отправляются); PostgreSQL + TimescaleDB; NuGet-пакеты Npgsql, Dapper, FluentMigrator, MediatR, `CryptoClients.Net` (
  Bybit.Net), Polly, Testcontainers, `Microsoft.AspNetCore.Mvc.Testing`; только в тестах — NSubstitute, Shouldly,
  AutoFixture.
- **Инфраструктура:** `docker-compose.yml` для локальной разработки; для интеграционных тестов нужен Docker.
  Production-сервер не затрагивается.
- **Конфигурация:** строка подключения к БД через переменные окружения / user secrets, не в git.
