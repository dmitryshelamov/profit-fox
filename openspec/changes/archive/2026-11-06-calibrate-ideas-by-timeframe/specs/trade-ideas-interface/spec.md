# Spec Delta

## MODIFIED Requirements

### Requirement: Чтение калибровки

API SHALL отдавать по `GET /api/ideas/calibration` итоги калибровки по параметрам: окно `days` — 90 или 30, по
умолчанию 90, категория `category` — `linear` или `spot`, без неё — все категории, и режим `scope` — `all` или `fresh`
(после изменения правил), по умолчанию `all`. Ответ SHALL содержать время расчёта, число проверенных случаев, число
случаев без статистики корзины, оценку Брайера, оценку без корзин, четыре таблицы калибровки, сравнение старой и новой
модели и разбивки по ТФ и по типу. Другое окно, категория или режим MUST давать ошибку валидации 400 с именем параметра.

#### Scenario: Калибровка за 30 дней по linear

- **WHEN** экран просит калибровку с `days=30` и `category=linear`
- **THEN** ответ содержит итоги только по случаям `linear`, сработавшим за последние 30 дней

#### Scenario: После изменения правил

- **WHEN** экран просит калибровку с `scope=fresh`
- **THEN** ответ содержит итоги только по случаям, сработавшим после применения правила своего типа × ТФ и начала версии

#### Scenario: Разбивки в ответе

- **WHEN** экран просит калибровку, посчитанную по случаям 5 мин и 1 ч типов «Цель 2R» и «Откат»
- **THEN** ответ содержит разбивку по ТФ со строками `5` и `60` и разбивку по типам со строками `target_2r` и `pullback`

#### Scenario: Итог, сохранённый до разбивок

- **WHEN** итог калибровки сохранён до появления разбивок
- **THEN** ответ содержит его таблицы и пустые разбивки

#### Scenario: Ещё не посчитана

- **WHEN** сканер ещё ни разу не посчитал калибровку
- **THEN** ответ без времени расчёта, с нулём проверенных случаев, пустыми таблицами и разбивками и без сравнения

#### Scenario: Другое окно

- **WHEN** экран просит калибровку с `days=60`
- **THEN** API отвечает ошибкой валидации 400 по параметру `days`

#### Scenario: Другой режим

- **WHEN** экран просит калибровку с `scope=old`
- **THEN** API отвечает ошибкой валидации 400 по параметру `scope`

## ADDED Requirements

### Requirement: Таблицы по ТФ и типам на экране «Калибровка»

Экран «Калибровка» SHALL показывать под таблицами калибровки таблицы «По ТФ» и «По типам»: по строке на ТФ или тип —
случаев, обещали и получили с интервалом 95 % по всем случаям, случаев с ▲, их обещали и получили с интервалом. Под
каждой SHALL быть таблица «старая модель → новая» с двумя строками на ТФ или тип: случаев, Брайер, случаев с ▲, обещали и
получили с интервалом. Разбивка без строк MUST NOT показываться.

#### Scenario: Таблица по ТФ

- **WHEN** у строки «1 ч» 4 000 проверенных случаев, обещали +0.02 R, получили −0.05 R, а у 900 случаев с ▲ обещали
  +0.15 R и получили −0.10 R
- **THEN** строка «1 ч» таблицы «По ТФ» показывает эти числа с интервалами

#### Scenario: Сравнение по типам

- **WHEN** в строке «Откат» у старой модели ▲ получил −0.08 R, а у новой +0.01 R
- **THEN** таблица «По типам: старая модель → новая» показывает для «Отката» строки «Старая» и «Новая» с этими итогами

#### Scenario: Итог без разбивок

- **WHEN** итог калибровки сохранён до появления разбивок
- **THEN** экран показывает плитки и таблицы калибровки без таблиц «По ТФ» и «По типам»
