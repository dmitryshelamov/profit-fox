# Tasks

Тесты запускаются из `frontend/`: `npm test`, `npm run typecheck`, `npm run lint`, `npm run format:check`,
`npm run build`. Бэкенд не меняется. Каждая задача начинается с теста, который без неё падает, и каждая группа
заканчивается зелёным прогоном всех проверок фронтенда.

Прежние тесты меняются только так. В группе 2 — тесты, которые рисовали идеи без выбора: им добавляется выбор идеи в
адресе, ожидания прежние, или они следуют изменённому сценарию «Идеи на графике» с прежними значениями (сколько меток
до выбора, одна выбранная идея вместо нескольких). В группе 3 — время (+3 часа: тесты идут в `Europe/Moscow`) и подпись
пояса («UTC» → «UTC+3»). Каждое такое изменение записывается в раздел «Открыто после применения» в конце этого файла;
любое иное — остановиться и спросить.

Порядок групп — порядок работы. Решения — `design.md`, номера в скобках. Ветка — `feat/fix-pair-chart-and-local-time`
от `release/0.1.0`.
