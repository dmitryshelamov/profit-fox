# Spec Delta

## ADDED Requirements

### Requirement: Поле аккаунта

Форма бота SHALL содержать поле «Аккаунт» со списком аккаунтов биржи, их окружением и вариантом «Без аккаунта» по
умолчанию. Ошибка сервера по аккаунту SHALL показываться у этого поля. Если аккаунтов нет, поле SHALL предлагать перейти
к добавлению аккаунта.

#### Scenario: Выбор аккаунта

- **WHEN** владелец выбирает в форме бота аккаунт «Проверка» и сохраняет
- **THEN** страница бота показывает аккаунт «Проверка»

#### Scenario: Ключ не торгует в категории

- **WHEN** сервер отклоняет бота с ошибкой по аккаунту
- **THEN** у поля «Аккаунт» ошибка сервера, остальные введённые значения на месте

### Requirement: Аккаунт на странице и в списке ботов

Страница бота и строка списка ботов SHALL показывать имя аккаунта бота со ссылкой на страницу аккаунта или пометку «Без
аккаунта». Бот с аккаунтом testnet SHALL быть отмечен меткой «Testnet».

#### Scenario: Бот на testnet

- **WHEN** у бота «BTC EMA час» аккаунт в окружении `testnet`
- **THEN** его строка в списке и страница бота отмечены меткой «Testnet»

#### Scenario: Бот без аккаунта

- **WHEN** у бота нет аккаунта
- **THEN** страница бота показывает «Без аккаунта»
