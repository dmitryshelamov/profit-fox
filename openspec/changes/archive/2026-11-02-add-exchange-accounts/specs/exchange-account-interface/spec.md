# Spec Delta

## Purpose

Веб-интерфейс аккаунтов биржи: владелец добавляет ключи Bybit, видит аккаунты с их окружением и балансом,
переименовывает и удаляет их.

## ADDED Requirements

### Requirement: Раздел аккаунтов

Шапка приложения SHALL содержать раздел «Аккаунты» после «Ботов». Раздел SHALL открываться списком аккаунтов, а у
каждого аккаунта SHALL быть прямая ссылка на его страницу.

#### Scenario: Переход в раздел

- **WHEN** владелец выбирает «Аккаунты» в шапке
- **THEN** открывается список аккаунтов, и пункт «Аккаунты» отмечен как текущий

### Requirement: Список аккаунтов

Интерфейс SHALL показывать список аккаунтов: имя, окружение, API key, UID Bybit и категории торговли. Аккаунт testnet
SHALL быть отмечен меткой «Testnet». Из списка SHALL открываться страница аккаунта и форма нового аккаунта. Пустой
список SHALL предлагать добавить аккаунт.

#### Scenario: Аккаунт testnet в списке

- **WHEN** среди аккаунтов есть аккаунт «Проверка» в окружении `testnet`
- **THEN** его строка отмечена меткой «Testnet»

### Requirement: Новый аккаунт

Форма нового аккаунта SHALL принимать имя, окружение (по умолчанию testnet), API key и secret. Поле secret MUST скрывать
вводимые символы. Сохранённый аккаунт SHALL открываться на своей странице. Если сервер отклоняет аккаунт, форма MUST
сохранить введённые значения, кроме secret, и SHALL показать каждую ошибку у её поля. Если биржа недоступна, форма SHALL
сказать об этом над кнопками.

#### Scenario: Аккаунт добавлен

- **WHEN** владелец вводит имя, выбирает testnet, вводит ключ, который принимает Bybit, и сохраняет
- **THEN** открывается страница нового аккаунта

#### Scenario: Ключ отклонён

- **WHEN** сервер отклоняет ключ с ошибкой по API key
- **THEN** у поля API key ошибка сервера, имя и API key на месте

### Requirement: Страница аккаунта

Страница аккаунта SHALL показывать имя, окружение, API key целиком, secret маской без символов ключа, UID Bybit,
категории торговли и ботов, привязанных к аккаунту, со ссылками на них. Баланс SHALL загружаться только по действию
«Показать баланс» и показываться таблицей монет с общим капиталом в USD.

#### Scenario: Secret маской

- **WHEN** владелец открывает страницу аккаунта
- **THEN** на месте secret маска `••••••••`, а API key показан целиком

#### Scenario: Баланс по действию

- **WHEN** владелец выбирает «Показать баланс»
- **THEN** страница показывает монеты с балансом, их стоимость в USD и общий капитал

#### Scenario: Биржа недоступна при чтении баланса

- **WHEN** владелец выбирает «Показать баланс», а сервер отвечает «биржа недоступна»
- **THEN** страница показывает, что Bybit недоступен, и остаётся рабочей

### Requirement: Переименование аккаунта

Владелец SHALL менять имя аккаунта на его странице. Ошибка сервера по имени SHALL показываться у поля.

#### Scenario: Новое имя

- **WHEN** владелец меняет имя аккаунта на «Основной» и сохраняет
- **THEN** страница и список аккаунтов показывают «Основной»

### Requirement: Удаление аккаунта

Удаление аккаунта SHALL требовать подтверждения. После удаления SHALL открываться список аккаунтов. Если сервер
отвечает конфликтом из-за привязанных ботов, страница SHALL показать имена этих ботов, и аккаунт SHALL остаться.

#### Scenario: Подтверждённое удаление

- **WHEN** владелец удаляет аккаунт без ботов и подтверждает
- **THEN** открывается список аккаунтов без этого аккаунта

#### Scenario: Аккаунт с ботами

- **WHEN** владелец удаляет аккаунт, к которому привязан бот «BTC EMA час»
- **THEN** страница показывает, что аккаунт используют боты, с именем «BTC EMA час», и аккаунт остаётся
