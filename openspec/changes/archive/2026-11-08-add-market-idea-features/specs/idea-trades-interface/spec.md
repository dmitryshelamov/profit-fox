# Spec Delta

## ADDED Requirements

### Requirement: Чипы признаков в строках сделок

Строки группы «В работе» и таблицы закрытых сделок SHALL показывать в колонке сетапа и типа чипы признаков идеи,
которые у сделки есть: «↓ пара», «↓ BTC» и «↑ funding», по наведению — полное название признака с границей. Без
признаков чипов MUST NOT быть.

#### Scenario: Учебная сделка с признаком

- **WHEN** у учебной сделки автомата «Лонг после падения» есть «падение пары за сутки»
- **THEN** в её строке после сетапа и типа чип «↓ пара»

#### Scenario: Сделка без признаков

- **WHEN** у сделки нет признаков
- **THEN** в её строке нет чипов
