# Design

## Context

- `IdeasHub` в `MarketPairPage.tsx` раскладывает страницу пары сеткой `lg:grid-cols-[22rem_1fr]`. Слева раздел «Идеи
  пары» (`PairIdeasList` — карточки `IdeaItem`) и `OwnIdeaBlock`, справа `PairChart`.
- `IdeasTable` на «Идеях» отрисовывает колонки из списка `headers`. Каждый заголовок сортирует таблицу через API, а клик
  по строке переходит на страницу пары. Ячейки — общие компоненты из `IdeaCells.tsx`.
- `groupPairIdeas` делит идеи пары на открытые и закрытые, сохраняя порядок API: по ожиданию.
- Идеи пишет только сканер, который держит аренду потока (`ScannerSession`). Полоса идей там же раз в 10 минут
  пересчитывает корзины. Корзины и прогон читают `idea_cases` и `idea_replay`, а не `ideas`. На `ideas` нет внешних
  ключей. Индекс `IX_ideas_status_at` уже есть.
- Минутный цикл обновляет по `id` только открытые идеи. Закрытая идея больше не меняется.

Почему меняем — см. proposal.md, требования — в specs.

## Goals / Non-Goals

**Goals:**

- Строка таблицы пары и строка «Идей» строятся из одних и тех же колонок и ячеек, чтобы не разойтись.
- Чистка не трогает минутный цикл и его бюджет в 5 секунд.

**Non-Goals:**

- Сортировка таблицы пары, сохранение раскрытия «Истёкших» между заходами.
- Менять срок показа закрытых идей (24 часа) и API.
- Настройка срока хранения в конфиге: 7 дней — константа, пока её не захочется менять.

## Decisions

### 1. Общие колонки, две таблицы

Из `IdeasTable` выносятся описание колонок (заголовок, выравнивание) и ячейки строки идеи. Колонка «Инструмент»
остаётся только у таблицы «Идей». Поверх общих частей две таблицы:

- `IdeasTable` — как сейчас: сортирующие заголовки, переход на страницу пары, ссылка на символ.
- `PairIdeasTable` — для страницы пары: заголовки без кнопок сортировки, выбор строки через `onSelect`, выделение
  выбранной, группа «Истёкшие».

Альтернатива — одна `IdeasTable` с флагами «без инструмента», «без сортировки», «выбор вместо перехода» и «группа
истёкших». Отказались: почти каждая ветка таблицы стала бы условной, а у двух экранов разные действия по клику.

Кнопка для клавиатуры: на «Идеях» это ссылка на символ. В таблице пары её роль берёт ячейка «Найдена» — кнопка с
`aria-pressed` у выбранной идеи. Клик по любой части строки делает то же самое.

### 2. «Истёкшие» — строка-переключатель внутри той же таблицы

Открытые и истёкшие строки стоят в одной `<table>`, чтобы колонки совпадали по ширине. Перед истёкшими идёт строка
`<th colSpan>` с кнопкой `aria-expanded` «Истёкшие · N». Строки истёкших отрисовываются, только пока группа раскрыта.
Состояние — `useState(false)` в таблице. Оно не зависит от выбранной идеи и сбрасывается при новом заходе на страницу.

Альтернатива — `<details>` с отдельной таблицей истёкших. Отказались: `<details>` нельзя вложить в `<table>`, а две
таблицы выравнивают колонки по-разному.

### 3. Раскладка страницы пары

`IdeasHub` идёт в одну колонку: `PairChart`, раздел «Идеи пары» с таблицей, `OwnIdeaBlock`. Таблица лежит в обёртке
`overflow-x-auto`: на узком экране 13 колонок прокручиваются внутри раздела, а не всей страницей. «Снять выбор»
остаётся в заголовке раздела «Идеи». Пояснения «Идея больше не в списке пары» и «Идеи больше нет» стоят там же, где
сейчас.

### 4. Чистка — в полосе идей сканера, раз в час

`IIdeaRepository.DeleteClosedBeforeAsync(DateTimeOffset closedBefore)` выполняет один
`DELETE FROM ideas WHERE status NOT IN ('awaiting_entry', 'active') AND status_at < @ClosedBefore` и возвращает число
удалённых строк. `LiveIdeas.RemoveClosedAsync` вызывает его с `now − 7 дней`. Полоса идей `ScannerSession` вызывает
его при старте сессии и затем раз в час, по тому же образцу, что пересчёт корзин (`bucketsAt`). Сбой ловит общий
`catch` полосы: `journal.Failed("ideas", …)` и повтор через 30 секунд.

Альтернативы:
- Минутный цикл — отказались: запись в базу добавилась бы к бюджету минуты.
- Фоновая служба в API — отказались: API может быть запущен в нескольких экземплярах, а писатель идей — один держатель
  аренды сканера.
- `pg_cron` или задача на сервере — отказались: это новая зависимость и вне кода.

Гонки с минутным циклом нет: он меняет только открытые идеи, а чистка удаляет только закрытые.

## Risks / Trade-offs

- [Выбранная истёкшая идея не видна в свёрнутой группе] → так решил владелец. Её уровни на графике и «Снять выбор»
  показывают, что она выбрана. Раскрыть группу — один клик.
- [Ожидание в USDT пропадает со страницы пары вместе с карточкой] → в строке остаются ожидание в R и прибыль / убыток в
  USDT, как на «Идеях». Если ожидание в USDT нужно, это отдельная колонка для обеих таблиц.
- [Первая чистка на проде удалит сразу всё старше 7 дней] → идеи на проде пишутся всего несколько дней, так что строк
  немного. Удаление идёт одним запросом по индексу `status_at`.
- [`take-idea-trades` свяжет сделки с идеями] → там же надо решить, что делать с идеей, по которой есть сделка. Сейчас
  на `ideas` никто не ссылается.

## Migration Plan

Миграций нет. Деплой — обычный выпуск: новая версия сканера при первой сессии удаляет старые закрытые идеи. Откат —
предыдущий образ: удалённые идеи не вернутся, но они и не нужны ни экрану, ни статистике.
