# Proposal

## Why

На странице пары идеи стоят карточками в узкой колонке слева, а график зажат справа. Карточки высокие: на экран влезают
четыре-пять идей. Истёкшие идеи за 24 часа идут сразу под открытыми и растягивают колонку ещё сильнее. Видна только
верхняя часть списка, а сравнить идеи по числам, как в таблице «Идеи», нельзя. Кроме того, закрытые идеи копятся в
таблице `ideas` без срока. На экран попадают только закрытые за 24 часа, а статистика их вообще не читает: корзины
считаются по `idea_cases`.

## What Changes

- Страница пары: график на всю ширину. Под ним раздел «Идеи» с таблицей идей пары, а ниже блок «Своя идея».
- Строка таблицы — та же, что на «Идеях»: найдена, сетап, ТФ, тип, сторона, вход, стоп, цель, R:R, вероятность,
  ожидание, прибыль / убыток, статус. Колонки «Инструмент» нет: на странице одна пара. Клик по строке выбирает идею для
  графика (`?idea=<id>`), выбранная строка выделена. Заголовки таблицы пары не сортируют: порядок остаётся как сейчас —
  открытые по ожиданию, затем истёкшие.
- Ожидание в USDT, которое сейчас есть в карточке пары, уходит вместе с карточкой. В строке, как и на «Идеях», есть
  ожидание в R и прибыль / убыток в USDT от «Суммы на идею».
- Группа «Истёкшие» — раскрывашка с числом идей в заголовке. Она всегда открывается свёрнутой и раскрывается только по
  клику, даже если в адресе выбрана истёкшая идея. Её уровни на графике показываются как сейчас.
- «Снять выбор» остаётся в заголовке раздела «Идеи».
- Сканер в фоне удаляет из хранилища идеи, закрытые («Цель», «Стоп», «Истекла») больше 7 дней назад. Экраны
  по-прежнему показывают закрытые за 24 часа. Ссылка `?idea=<id>` на удалённую идею показывает «Идеи больше нет», как
  сейчас для неизвестной идеи.

Не меняется: API списка идей пары и `GET /api/ideas/{id}`, раздел «Идеи», корзины и статистика, прогон по истории,
блок «Своя идея» и его уровни на графике.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `trade-ideas-interface`: раскладка страницы пары, таблица идей пары вместо карточек, свёрнутая группа «Истёкшие»,
  выделение выбранной строки.
- `trade-ideas`: срок хранения закрытых идей — 7 дней после закрытия.

## Impact

- Frontend:
  - `MarketPairPage` / `IdeasHub`: раскладка в одну колонку — график, раздел «Идеи», «Своя идея»;
  - `IdeasTable` получает режим пары: без колонки «Инструмент» и сортировки, выбор строки вместо перехода;
  - `PairIdeasList` вместо карточек показывает таблицу и раскрывашку «Истёкшие»;
  - тесты страницы пары (`marketPairIdeas.test.tsx`) и e2e `ideas.spec.ts`.
- Backend:
  - `IIdeaRepository` / `IdeaRepository`: удаление закрытых раньше заданного момента;
  - полоса идей `ScannerSession` раз в час удаляет закрытые идеи старше 7 дней;
  - unit- и integration-тесты на это.
- Миграции не нужны: индекс `IX_ideas_status_at` уже есть. API не меняется.
- Прод: при первом запуске новой версии сканер удалит все идеи, закрытые раньше 7 дней назад.
