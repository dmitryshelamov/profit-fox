# Spec Delta

## MODIFIED Requirements

### Requirement: Детали результата

Система SHALL возвращать детали результата: исполнения (время, сторона, цена, объём, комиссия), сделки (открытие,
закрытие, средний вход, средний выход, PnL, комиссии) и кривую капитала. Детали SHALL пересчитываться по версии
стратегии, правилам и настройкам бэктеста и MUST совпадать с метриками результата. Детали результата бэктеста, версия
движка которого отличается от текущей версии движка API, MUST отклоняться как конфликт с обеими версиями в ответе.

#### Scenario: Детали после правки стратегии

- **WHEN** после бэктеста стратегию бота изменили, и пользователь открывает детали результата
- **THEN** детали посчитаны по версии стратегии бэктеста, и PnL по ним равен PnL результата

#### Scenario: Детали бэктеста другой версии движка

- **WHEN** бэктест посчитан версией движка `2`, а API работает с версией движка `3`, и пользователь открывает детали
  результата
- **THEN** система отвечает конфликтом, где названы версии `2` и `3`, а список результатов бэктеста по-прежнему
  читается
