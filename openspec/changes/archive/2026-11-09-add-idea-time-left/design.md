# Design

## Context

- Сделка (`IdeaTrade`) не хранит срок жизни своей идеи: у неё есть только `IdeaId`, `EntryDeadline` окна входа и
  `IdeaOutcome`, который сканер записывает, когда идея закрывается.
- Срок жизни идеи — в её `IdeaTrack`: `EnteredAt`, `LifeCandles`, `CandleMinutes`. `IdeaTracker.Exit` закрывает идею
  «Истекла» на закрытии минуты, конец которой не раньше `EnteredAt + LifeCandles × CandleMinutes`.
- `GetIdeaJournalQueryHandler` уже собирает сделки в работе отдельно от закрытых и дочитывает к ним цены; идей он не
  читает.
- Таблица `OpenTradesTable` тикает раз в минуту через `useNow` и показывает «В сделке» через `durationText`.

## Goals / Non-Goals

**Goals:**

- Один момент конца идеи на сделку в работе, посчитанный на бэкенде по тому же правилу, по которому идея истекает.

**Non-Goals:**

- Не записываем срок идеи на сделку и не меняем схему БД.
- Не показываем окно входа идеи, что ещё ждёт входа (решено с владельцем: «—»).
- Закрытые сделки, учебные автоматы и сканер не меняются.

## Decisions

1. **Момент конца жизни — свойство `IdeaTrack`.** `IdeaTrack.LifeEndsAt` = `EnteredAt + LifeCandles × CandleMinutes`,
   нет без входа. `IdeaTracker.Exit` переходит на него рефакторингом, чтобы правило истечения и показ не разошлись.
   Альтернатива — считать в обработчике журнала: дублирует формулу.
2. **Журнал дочитывает идеи сделок в работе одним запросом по id.** Новый метод `IIdeaRepository.GetManyAsync(ids)`
   отдаёт хранящиеся идеи по списку id. Альтернатива `GetOpenAsync` читает все открытые идеи всех пар — их тысячи против
   десятков сделок в работе. Закрытые сделки идей не читают.
3. **Момент отдаётся только у активной идеи.** В обработчике: идея найдена и `Status == Active` → `LifeEndsAt`, иначе
   нет. «закрыта» фронтенд берёт из уже отдаваемого `ideaOutcome`, отдельного флага не нужно: исход пишется в той же
   транзакции, что закрывает идею, и переживает её чистку.
4. **Контракт.** `IdeaJournalTrade` получает `IdeaEndsAt`, `IdeaTradeResponse` — `ideaEndsAt` (`DateTimeOffset?`).
   Абсолютный момент, а не «секунд осталось»: таблица уже тикает по `useNow`, и ответ не устаревает между запросами.
5. **Текст колонки — чистая функция в `idea-trades/model/journal.ts`.** `ideaLeftText(trade, now)`: `ideaOutcome` есть →
   «закрыта»; `ideaEndsAt` есть → `durationText(max(0, ideaEndsAt − now))`, что даёт «< 1 мин» после конца; иначе «—».
   Порядок проверок по исходу первым: у закрытой идеи момента и так нет, но исход однозначнее.

## Risks / Trade-offs

- [Идея закрылась между чтением сделок и чтением идей] → момента нет, исхода в ответе ещё нет: колонка покажет «—» до
  следующего опроса журнала. Приемлемо.
- [Сканер отстаёт, и срок уже вышел] → «< 1 мин», пока сканер не закроет идею; см. сценарий спеки.
- [Лишний запрос на журнал] → один запрос по первичному ключу на все сделки в работе, только когда они есть.

## Migration Plan

Без миграций: поле в ответе новое и необязательное. Откат — откат образа.
