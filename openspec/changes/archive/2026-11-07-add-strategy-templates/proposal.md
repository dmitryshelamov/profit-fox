# Proposal

## Why

В ProfitGraph у владельца было 15 готовых шаблонов стратегий: пересечения средних, лесенки, DCA, индикаторные входы по
MACD, RSI и Боллинджеру, откуп капитуляции, импульс на объёме, сделка по уровням. В profit-fox новая стратегия
начинается с пустого холста, а эталоны EMA, EMA Short, Ladder и DCA есть только в тестах; из индикаторов в библиотеке
одна EMA. Владелец решил перенести шаблоны сейчас, чтобы стратегии можно было не собирать с нуля, и вместе с ними
добавить узлы, без которых их не выразить. Решение 2026-11-01 «отдельной функции шаблонов нет» этим пересматривается.

## What Changes

- Каталог из 14 встроенных шаблонов: EMA Crossover (со стопом), EMA Short, SMA Crossover, Ladder, Ladder SMA, Ladder+,
  DCA, MACD по тренду, Отскок RSI, Возврат от полосы Боллинджера, Откуп капитуляции, Импульс на объёме, Сделка по
  уровням, Сделка по уровням (шорт). Шаблон — определение стратегии в коде с названием и описанием; API отдаёт список и
  определение.
- «Новая стратегия» предлагает пустой холст или шаблон. Шаблон открывается обычным черновиком новой стратегии со своим
  графом и становится обычной стратегией владельца при первом сохранении. Связи с шаблоном у неё нет: ни вида шаблона,
  ни правил параметров по шаблону, ни обновлений при изменении шаблона.
- Новые простые узлы: SMA, RSI (сглаживание Уайлдера), стандартное отклонение и «Предыдущее» — значение входа на
  предыдущей закрытой свече. Все считаются в `decimal`.
- Новые встроенные составные узлы: MACD (линия, сигнальная, гистограмма) и полосы Боллинджера (верхняя, средняя,
  нижняя).
- Узел позиции получает три новых выхода: число закрытых свечей с последнего входа, реализованный PnL закрытых позиций
  бота или бэктеста и число закрытых позиций.
- Узел «закрыть позицию» сначала отменяет другие ордера выхода позиции и ставит рыночный выход только после
  подтверждения их отмены, чтобы стоящая лимитная продажа и рыночный выход не продавали один объём дважды. Сейчас ни
  одна эталонная стратегия не держит лимитный выход вместе с этим узлом, поэтому их команды не меняются.

Вне изменения: шаблон «Сетка» (свой вид исполнения с лотами по уровням — отдельное изменение сразу после этого),
связь шаблонов со сканером и торговыми идеями, правила параметров по шаблону, точная сверка результатов с бэктестами
ProfitGraph, ATR и другие индикаторы, которые не нужны ни одному из 14 шаблонов.

## Capabilities

### New Capabilities

- `strategy-templates`: каталог встроенных шаблонов стратегий — состав, чтение списка и определения, корректность
  каждого шаблона и его эталонное поведение.

### Modified Capabilities

- `strategy-execution`: узлы SMA, RSI, стандартного отклонения и «Предыдущее»; новые выходы узла позиции и их
  восстановление после рестарта; «закрыть позицию» отменяет другие ордера выхода, прежде чем выходить.
- `strategy-library`: встроенные составные узлы MACD и «Полосы Боллинджера» рядом с «Пересечением EMA».
- `strategy-editor`: новая стратегия из шаблона; новые узлы в палитре.

## Impact

- `ProfitFox.Domain`: `SimpleNodeKind`, `SimpleNodeCatalog`, состояния и вычисление узлов в `StrategyRun`, `Position`
  (счётчик свечей с последнего входа), `BuiltInComposites` и `BuiltInNode`, шаблоны как встроенные определения.
- `ProfitFox.Application` и `ProfitFox.Presentation`: запросы и контроллер шаблонов (`GET /api/strategy-templates`,
  `GET /api/strategy-templates/{code}`), коды новых узлов в `StrategyJson`.
- Живая торговля: прогрев и восстановление узлов идут прежним путём (`WarmUp`, `RunSnapshot`); новых данных в базе нет.
- Фронтенд: выбор шаблона на странице стратегий, черновик новой стратегии из шаблона, группы палитры, сгенерированная
  схема API.
- Тесты: эталонные значения новых узлов и шаблонов на маленьких наборах; эталонные результаты бэктестов и версия
  движка меняться не должны.
