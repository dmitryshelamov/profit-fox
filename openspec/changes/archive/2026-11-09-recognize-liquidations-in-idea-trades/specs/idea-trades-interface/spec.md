## ADDED Requirements

### Requirement: Статусы ликвидации и ADL в таблице

В таблице закрытых сделок статус `liquidated` SHALL подписываться «Ликвидирована», а `closed_by_adl` — «Закрыта биржей
(ADL)». У обоих SHALL быть результат в USDT и R и время до исхода, как у закрытых по цели и по стопу.

#### Scenario: Ликвидированная сделка

- **WHEN** сделку JCTUSDT ликвидировала биржа с результатом −0.24 R за 8 мин
- **THEN** в её строке «Ликвидирована», «−0.24 R» и «8 мин»

#### Scenario: Закрытая по ADL

- **WHEN** сделку закрыла биржа по ADL с результатом +0.50 R
- **THEN** в её строке «Закрыта биржей (ADL)» и «+0.50 R»

## MODIFIED Requirements

### Requirement: Итоги на экране «Сделки»

Над таблицей закрытых сделок SHALL стоять два блока итогов журнала по фильтру: «С деньгами» и «Учебные». В каждом:
сделки по цели, по стопу, вручную и по сроку с их долями, отменённые и с ошибкой, сумма в USDT, комиссии, средний R с
интервалом, среднее время до исхода, «обещали X R → получили Y R · N» и «идеи X R → сделки Y R · N». Ликвидированные и
закрытые по ADL SHALL стоять в ряду исходов с долями, только когда их больше нуля, и входить в число закрытых сделок.
Сравнение без сделок SHALL показываться «—». Если по фильтру «Кто взял» один вид сделок, SHALL стоять только его блок.

#### Scenario: Итоги

- **WHEN** по фильтру 4 сделки: по цели 1, по стопу 1, вручную 1, по сроку 1, средний R +0.3
- **THEN** итоги показывают «по цели 1 (25 %) · по стопу 1 (25 %) · вручную 1 (25 %) · по сроку 1 (25 %)» и «+0.30 R»
  с интервалом

#### Scenario: Сравнивать не с чем

- **WHEN** ни у одной закрытой сделки фильтра нет обещания
- **THEN** вместо «обещали → получили» стоит «—»

#### Scenario: Только учебные

- **WHEN** владелец выбрал «Кто взял: Учебные»
- **THEN** стоит только блок «Учебные»

#### Scenario: Есть ликвидация

- **WHEN** по фильтру 4 сделки: по цели 1, по стопу 2, ликвидирована 1
- **THEN** итоги показывают «по цели 1 (25 %) · по стопу 2 (50 %) · вручную 0 (0 %) · по сроку 0 (0 %) · ликвидировано 1
  (25 %)», «ADL» не показан, а число закрытых — «4 сделки»
