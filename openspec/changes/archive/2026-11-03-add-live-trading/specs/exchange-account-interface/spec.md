# Spec Delta

## MODIFIED Requirements

### Requirement: Новый аккаунт

Форма нового аккаунта SHALL принимать имя, API key и secret. Поле secret MUST скрывать вводимые символы. Сохранённый
аккаунт SHALL открываться на своей странице. Если сервер отклоняет аккаунт, форма MUST сохранить введённые значения,
кроме secret, и SHALL показать каждую ошибку у её поля. Если биржа недоступна, форма SHALL сказать об этом над кнопками.

#### Scenario: Аккаунт добавлен

- **WHEN** владелец вводит имя, ключ, который принимает Bybit, и сохраняет
- **THEN** открывается страница нового аккаунта

#### Scenario: Ключ отклонён

- **WHEN** сервер отклоняет ключ с ошибкой по API key
- **THEN** у поля API key ошибка сервера, имя и API key на месте

### Requirement: Страница аккаунта

Страница аккаунта SHALL показывать имя, API key целиком, secret маской без символов ключа, UID Bybit, категории
торговли и ботов, привязанных к аккаунту, со ссылками на них. Баланс SHALL загружаться только по действию «Показать
баланс» и показываться таблицей монет с общим капиталом в USD.

#### Scenario: Secret маской

- **WHEN** владелец открывает страницу аккаунта
- **THEN** на месте secret маска `••••••••`, а API key показан целиком

#### Scenario: Баланс по действию

- **WHEN** владелец выбирает «Показать баланс»
- **THEN** страница показывает монеты с балансом, их стоимость в USD и общий капитал

#### Scenario: Биржа недоступна при чтении баланса

- **WHEN** владелец выбирает «Показать баланс», а сервер отвечает «биржа недоступна»
- **THEN** страница показывает, что Bybit недоступен, и остаётся рабочей

## ADDED Requirements

### Requirement: Список аккаунтов биржи

Интерфейс SHALL показывать список аккаунтов: имя, API key, UID Bybit и категории торговли. Из списка SHALL открываться
страница аккаунта и форма нового аккаунта. Пустой список SHALL предлагать добавить аккаунт.

#### Scenario: Аккаунт в списке

- **WHEN** среди аккаунтов есть аккаунт «Основной» с категориями `spot` и `linear`
- **THEN** его строка показывает имя, API key, UID и обе категории

## REMOVED Requirements

### Requirement: Список аккаунтов

**Reason**: Окружение testnet убрано из продукта. Метки «Testnet» больше нет.
