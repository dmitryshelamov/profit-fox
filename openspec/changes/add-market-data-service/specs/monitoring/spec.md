# Spec Delta

## ADDED Requirements

### Requirement: Метрики машины сервиса приходят в мониторинг

Сервис рыночных данных на своей машине и сверка на soyo-01 SHALL отправлять метрики в Prometheus на soyo-03 по локальной
сети. Порты для этого на их машинах MUST NOT публиковаться.

#### Scenario: Метрики сервиса

- **WHEN** сервис работает на мини-ПК и сверка на soyo-01
- **THEN** в Prometheus есть метрики с именами сервисов `market-data` и `market-data-parity`

### Requirement: Дашборд «Сервис рыночных данных»

Grafana SHALL показывать дашборд «Сервис рыночных данных», который подготовлен в репозитории. На нём:
- отставание закрытых данных по потокам и наибольшее по парам;
- разрывы потоков;
- прогресс истории по видам данных;
- подписчики, их очередь и подписки, закрытые за отставание;
- запросы сервиса к Bybit REST против его потолка;
- счётчики сверки: сверенные значения, объяснённые и необъяснённые расхождения и дыры по видам данных.

#### Scenario: Решение о переезде

- **WHEN** владелец открывает дашборд за последние 7 дней
- **THEN** он видит, были ли необъяснённые расхождения или дыры по каждому виду данных и когда

#### Scenario: Сервис отстал

- **WHEN** сервис 10 минут не записывает закрытые минуты
- **THEN** на панели отставания видна линия, выросшая выше 10 минут
