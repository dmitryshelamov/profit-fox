# Spec Delta

## MODIFIED Requirements

### Requirement: Настройки торговли

Worker SHALL читать из настроек, включена ли торговля; по умолчанию она выключена. Каждый Worker SHALL получать
мастер-ключ аккаунтов биржи и вне окружений разработки и тестов MUST NOT запускаться без него, сообщив причину в журнал:
торгующий Worker расшифровывает им ключи ботов, любой Worker — токен аккаунта T-Invest для загрузки свечей `moex`.

#### Scenario: Торговля без мастер-ключа

- **WHEN** Worker запускают в окружении `Production` с включённой торговлей и без мастер-ключа
- **THEN** Worker не запускается и пишет в журнал, что мастер-ключ не задан

#### Scenario: Worker только для бэктестов без мастер-ключа

- **WHEN** Worker запускают в окружении `Production` с выключенной торговлей и без мастер-ключа
- **THEN** Worker не запускается и пишет в журнал, что мастер-ключ не задан

#### Scenario: Worker только для бэктестов

- **WHEN** Worker запускают в окружении `Production` с выключенной торговлей и с мастер-ключом
- **THEN** Worker запускается и считает бэктесты
