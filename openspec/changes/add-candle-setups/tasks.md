# Tasks

Расчётная логика — строго red → green → refactor. Каждый сетап и правило проверяются на эталонных наборах в
`backend/tests/ProfitFox.Tests.Shared/Fixtures/Ideas` с заранее посчитанными ответами. Прод в этом изменении не
трогаем: подбор порогов — после выкладки и с разрешения владельца.

  свечах с посчитанными RSI. Значение не зависит от числа свечей сверх 100.

## Workflow follow-up

- Владелец ревьюит артефакты; правки — через `/opsx:update`.
- После `/opsx:apply` — ревью, `/opsx:archive` и PR одним squash-коммитом.
- После выкладки — подбор порогов новых сетапов повторными прогонами на soyo-01, только с разрешения владельца.
