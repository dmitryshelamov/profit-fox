# Spec Delta

## ADDED Requirements

### Requirement: Арифметические узлы в каталоге сигнала

Каталог узлов сигнала SHALL содержать узлы `add`, `subtract` и `multiply` в группе «Числа» с названиями «Сложить»,
«Вычесть» и «Умножить». Палитра редактора сигнала SHALL показывать их вместе с остальными узлами каталога.

#### Scenario: Арифметика в каталоге

- **WHEN** запрашивают каталог узлов сигнала
- **THEN** у `multiply` входы `a` и `b` и выход `result` типа «число», группа «Числа», название «Умножить»

#### Scenario: Порог от другого значения

- **WHEN** в сигнале выход узла `multiply` подключён ко входу `b` узла сравнения
- **THEN** проверка сигнала не находит ошибок
