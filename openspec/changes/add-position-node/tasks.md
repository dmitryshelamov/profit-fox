# Tasks

Тесты бэкенда запускаются из `backend/`: `dotnet test ProfitFox.slnx`; фронтенда — из `frontend/`: `npm test`,
`npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run build`. Каждая задача начинается с теста, который
без неё падает, и каждая группа заканчивается зелёным прогоном всех тестов своей части.

Не правятся ни в одной задаче: ожидания `EngineVersionTests`, `H0001ParityTests`, `H0001StrategyParityTests`,
`SignalNodeParityTests`, `HypothesisRunTests`, `OverlapRunTests`, `ParityThroughWorkerTests`, `TradeSimulatorTests`,
`OutcomeParityTests` и файл `Tests.Integration/Fixtures/EngineVersions.json`; `EngineVersion.Number` остаётся `2`. Если
задача требует их тронуть — остановиться и записать это в «Открыто после применения».
