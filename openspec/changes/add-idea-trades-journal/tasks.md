# Tasks

Новая логика идёт строго по TDD: красный тест, минимальный код, рефакторинг. Тесты и локальные запуски ходят только в
заглушку Bybit или в подменённый транспорт, реальных ордеров нет.

## 0. База

- [x] 0.1 Дождаться мержа PR #46 и перебазировать ветку `feat/add-idea-trades-journal` на `main`. Готово, когда ветка
  стоит на `main` с коммитом #46 и сборка зелёная.

## 1. Домен

- [x] 1.1 `IdeaPromise` и поле `IdeaTrade.Promise`; `IdeaTrade.Create` принимает обещание. Готово, когда NUnit
  проверяет, что созданная сделка несёт переданное обещание, а сделка без обещания создаётся с `null`.
- [x] 1.2 `IdeaTrade.OpenedAt`: ставится при переходе «Ждёт входа» → «Открыта» и больше не меняется при следующих
  исполнениях входа и выходах. Готово, когда NUnit на частичном и полном входе даёт время первого исполнения.
- [x] 1.3 `IdeaOutcome` и поле `IdeaTrade.IdeaOutcome`. Итог живой идеи — `CaseResult.R`, у идеи без входа итога нет.
  Готово, когда NUnit на «Цель» и на «Откат» без входа даёт сценарии требования «Исход идеи на сделке».
- [x] 1.4 `IdeaTrade.ResultAt(price, takerPercent)`: вышедшая часть плюс остаток по цене с taker, минус комиссия
  входа, и он же в R; у «Ждёт входа» пусто. Готово, когда NUnit даёт число сценария «Открытая в плюсе» и учитывает
  частичный выход.
- [x] 1.5 `IdeaJournalTotals.Compute`: счёт по исходам, сумма USDT, комиссии, средний R с интервалом (нет при N = 1, нет
  среднего при N = 0), среднее время до исхода, «обещали → получили», «идеи → сделки». Готово, когда NUnit на сценариях
  требований «Итоги журнала» и «Обещание против итога» даёт ожидаемые числа.

## 2. Хранение

- [x] 2.1 Миграция `AddIdeaTradeJournal` (номер после `202611070006`): колонки обещания, исхода идеи, `opened_at`;
  заполнение `opened_at` по самому раннему исполнению ордера входа. Готово, когда интеграционный тест миграции на
  сделке с исполнениями даёт `opened_at`, а сделка без исполнений — `NULL`.
- [x] 2.2 `IdeaTradeDb`, конвертер и `INSERT` пишут обещание; `Save` пишет `opened_at` и не перечисляет колонки
  обещания и исхода. Готово, когда тест хранения: сделка с обещанием сохраняется Worker'ом, а обещание и записанный
  исход идеи остаются.
- [x] 2.3 `IdeaRepository.SaveAsync` в транзакции минуты пишет исход закрывшихся идей на их сделки без исхода, не
  трогая `updated_at`. Метод догонки: сделкам без исхода с закрытой хранимой идеей. Готово, когда интеграционные тесты
  видят исход после закрытия идеи и после догонки, а `updated_at` сделки не изменился.

## 3. Сканер

- [x] 3.1 `LiveIdeas` передаёт в `SaveAsync` исходы закрывшихся идей с итогом `CaseResult.R` по комиссиям категории.
  Готово, когда тест `LiveIdeas` на закрытии идеи «Цель» передаёт её итог в R, а на «Откате» без входа — без итога.
- [x] 3.2 Догонка исходов при старте сессии сканера; сбой пишется в лог и не мешает снимку и идеям. Готово, когда
  тест сессии вызывает догонку один раз при старте, а падение догонки не останавливает цикл.

## 4. Вход

- [x] 4.1 `IdeaTradeEntryCalculator` читает корзины текущей версии и строит обещание через `IdeaView.Of`; безубыток и
  R:R после комиссий — от цены входа сделки. `CreateIdeaTradeCommandHandler` пишет обещание. Готово, когда
  интеграционный тест входа видит обещание сценариев «Вход на ▲» и «Мало данных», а пересчёт корзины после входа его
  не меняет.

## 5. API журнала

- [x] 5.1 `GetIdeaJournalQuery` и обработчик: разбор `Setup`, `Symbol`, `Side`, `Badge`, `Days`, `Page`, `PageSize` с
  ошибками по имени параметра; отбор, «В работе» от новых, закрытые по времени закрытия, срез страницы, итоги по
  всем закрытым фильтра. Готово, когда тесты обработчика покрывают сценарии «Чтение журнала» и «Фильтры журнала».
- [x] 5.2 Последняя цена по символу каждой открытой сделки, один запрос на символ; ошибка даёт пустой текущий
  результат. Готово, когда тест с подменённым клиентом даёт текущий результат и сценарий «Bybit не ответил».
- [x] 5.3 `GET /api/idea-trades` отдаёт журнал (`IdeaJournalResponse`: `open`, `closed`, `totals`; сделка с временем

  с 400. Готово, когда `IdeaTradesApiTests` проверяют форму ответа, страницу, фильтр и 400 по размеру, а старые тесты
  списка переписаны на журнал.
- [x] 5.4 `docs/conventions.md`: новые типы в списках областей. Готово, когда каждый новый тип есть в документе.
