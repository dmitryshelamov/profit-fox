# Proposal

## Why

Идеи сканера сейчас только подсказывают: на экране «Только просмотр: отсюда ничего не торгуется». Чтобы войти по идее,
владелец вручную переносит вход, стоп, цель и объём на Bybit. Это медленно, и объём по риску приходится считать в уме.
По плану сканера следующий шаг — бот идей в ручном режиме: вход по клику с реальными деньгами. Решения согласованы в
`/grill-me` 2026-11-05.

## What Changes

- **Новая сущность «Сделка по идее»: вход, стоп и цель на бирже.** Владелец нажимает «Войти» в строке открытой идеи.
  Система ставит на Bybit один вход с прикреплёнными стоп-лоссом и тейк-профитом:
  - на `linear` — в режиме `Partial`, только на объём этой сделки;
  - на `spot` — на лимитном входе.

  Стоп и цель живут на бирже и срабатывают, даже когда Worker не работает. Работают оба рынка, `linear` и `spot`.
- **Объём по риску.** Объём = риск в USDT / убыток на 1 USDT после комиссий, но сумма сделки не больше «Не больше суммы
  на сделку».
- **Вход.**
  - «Откат» входит лимиткой по цене идеи. Лимитка живёт до срока входа идеи, остаток в срок снимается.
  - Остальные типы входят по текущей цене: на `linear` по рынку, на `spot` лимиткой IOC по текущей цене. Стоп и цель
    берутся из идеи.
- **Когда вход отклоняется.** Перед входом система пересчитывает R:R после комиссий от текущей цены. Вход отклоняется с
  причиной, если:
  - цена уже за стопом или за целью;
  - R:R ниже минимального;
  - нарушено «Не больше открытых сделок» или «Не больше общего риска»;
  - на символе `linear` этого аккаунта открыта противоположная сторона — запущенный бот или другая сделка по идее;
  - не хватает свободных денег;
  - объём меньше минимального ордера биржи;
  - ключ не торгует категорию;
  - на аккаунте включён hedge.
- **Жизнь сделки.** Сделку ведёт торговый Worker, как ботов: аренда, сохранение ордера до отправки, детерминированный
  `orderLinkId`, приватный поток, догрузка после перерыва. Статусы:
  - «Ждёт входа»;
  - «Открыта»;
  - «Закрыта по цели», «Закрыта по стопу», «Закрыта вручную»;
  - «Отменена»;
  - «Ошибка».

  Результат — в USDT после комиссий и в R. Кнопки: «Отменить», пока вход не исполнен, и «Закрыть по рынку».
- **Сделки рядом с ботами.** Сделки по идеям могут быть на любом аккаунте вместе с ботами. Их позиции входят в сверку
  аккаунта и инструмента и в проверку денег. Их ордера, включая TP/SL, которые создаёт биржа, не считаются чужими.
  Пока открыта сделка по идее, на её символе `linear` не запускается бот противоположного направления.
- **Настройки «Торговля идеями».** Хранятся на сервере:
  - аккаунт по умолчанию;
  - риск на сделку;
  - «Не больше суммы на сделку»;
  - «Не больше открытых сделок»;
  - «Не больше общего риска»;
  - минимальный R:R после комиссий.

  Окно входа позволяет поменять риск и аккаунт для одной сделки.
- **Экраны.**
  - кнопка «Войти» в строке идеи в таблице идей на странице пары;
  - окно входа с расчётом и причинами отказа;
  - раздел «Сделки» после «Идеи»: список сделок, их кнопки и настройки.
- **Заглушка Bybit для e2e.** Учится прикреплённым TP/SL, условным ордерам, их срабатыванию по цене и позиции символа
  `linear`. Тесты и локальные запуски реальных ордеров не отправляют.
- **Проверка на споте.** Документация Bybit связывает дочерние TP/SL с входом через `parentOrderLinkId` только для
  фьючерсов. Как узнать свои TP/SL на споте, проверяется одной минимальной реальной сделкой с отдельного разрешения
  владельца. Если связи нет, на споте работает запасной вариант из design.md.

Вне изменения: автоматический режим, дневной стоп по убытку, журнал идей, режим hedge, управление плечом (нужны деньги на
позицию при 1×, как у ботов), уведомления, сделка на графике пары.

## Capabilities

### New Capabilities

- `idea-trades`: сделка по идее — настройки, расчёт и проверки входа, вход с TP/SL на бирже, жизнь сделки в торговом
  Worker'е, отмена и закрытие, восстановление, место сделок в сверке и в проверке денег.
- `idea-trades-interface`: «Войти» в строке идеи в таблице на странице пары, окно входа, раздел «Сделки» и настройки торговли
  идеями; подпись «Только просмотр» на «Идеях» меняется.

### Modified Capabilities

- `live-trading`: в проверку денег при запуске и в сверку входят сделки по идеям; их исполнения не чужие; запуск бота
  противоположного направления на символе открытой сделки отклоняется; при расхождении сделка по идее уходит в
  «Ошибку», а её TP/SL остаются на бирже.

## Impact

- **Backend.**
  - Новые сущность, таблицы и миграция сделок по идеям.
  - Сессия сделки в торговом Worker'е рядом с `LiveBotSession`, аренды сделок.
  - `ClientOrderId` получает вид для сделки.
  - `OrderRequest` и `BybitOrderGateway` получают TP/SL, `tpslMode`, `positionIdx` и `reduceOnly`.
  - Поток ордеров передаёт `parentOrderLinkId` и тип стоп-ордера.
  - `LiveBotReconciler` и `StartFunds` учитывают сделки.
  - API: настройки, предпросмотр, вход, список, отмена, закрытие.
  - Чтение текущей цены у Bybit для предпросмотра и входа.
- **Frontend.** Модуль `idea-trades`, страница «Сделки», окно входа, кнопка в `PairIdeasList`, перегенерированный
  `schema.d.ts`.
- **E2E.** Заглушка Bybit `frontend/e2e/bybit-stub.ts` и интеграционные `FakeExchange`/`FakeBybitHandler`.
- **Прод.** Миграция базы. Реальные ордера ставит только торговый Worker на soyo-01 с мастер-ключом. Перед первой
  сделкой на споте — одна минимальная проверочная сделка с отдельного разрешения владельца.
