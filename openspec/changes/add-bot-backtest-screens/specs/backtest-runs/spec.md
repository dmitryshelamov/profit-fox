# Spec Delta

## MODIFIED Requirements

### Requirement: Чтение бэктестов

Система SHALL возвращать бэктест по идентификатору: бота, версию стратегии, версию движка, период, значения и
диапазоны параметров, настройки симуляции, правила инструмента, статус, причину ошибки, прогресс и скорость. Список
бэктестов бота SHALL идти от новых к старым и содержать у каждого период, значения и диапазоны параметров, статус,
причину ошибки, прогресс и отметку «бот изменился». Список бэктестов неизвестного бота SHALL давать ответ «не
найдено».

#### Scenario: Список бэктестов бота

- **WHEN** у бота созданы бэктесты `A`, затем `B`
- **THEN** список бэктестов бота возвращает `B`, затем `A`

#### Scenario: Бэктесты неизвестного бота

- **WHEN** пользователь запрашивает список бэктестов бота, которого нет
- **THEN** система отвечает «не найдено»

#### Scenario: Диапазоны и ошибка в списке

- **WHEN** бэктест задал `fast` диапазоном `5`, `15`, `5` и завершился `Failed` с причиной загрузки свечей
- **THEN** элемент списка содержит диапазон `fast`, статус `Failed` и эту причину

#### Scenario: Бот изменился в списке

- **WHEN** после бэктеста `A` стратегию бота сохранили с изменённым графом, а бэктест `B` создан после этого
- **THEN** список бэктестов бота отмечает «бот изменился» у `A` и не отмечает у `B`
