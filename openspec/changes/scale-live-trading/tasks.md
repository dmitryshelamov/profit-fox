## 1. Общие потоки Bybit

- [x] 1.1 `FakeBybitSocketServer`: считать открытые соединения по адресу (`/v5/public/spot`, `/v5/public/linear`,
  `/v5/private`) и запросы `subscribe` по топику — существующие `BybitStreamsTests` и `LiveTradingTests` зелёные
- [x] 1.2 `BybitStreams`: один публичный клиент на процесс и одна подписка SDK на пару «категория + символ + интервал»
  со списком подписчиков — тесты «три пары у десяти подписчиков — одно соединение и три подписки», «два подписчика
  одной пары — одна подписка, свечу получают оба», «спот и линейные — два соединения»; при необходимости
  `SocketSubscriptionsCombineTarget` не больше 100
- [x] 1.3 Отписка: последний подписчик снимает подписку, клиент без подписок закрывается; подписка и отписка одного
  ключа под одним замком — тесты «последний отписавшийся снимает топик, остальные пары приходят дальше» и
  «одновременные подписка и отписка одной пары не оставляют двух подписок»
- [x] 1.4 Приватный клиент на ключ аккаунта с `order` и `execution`, события раздаются всем подписчикам ключа — тест
  «три подписчика аккаунта — одно приватное соединение, одна авторизация, ордер и сделку получают все»
- [x] 1.5 Восстановление и отказ: `ConnectionRestored` зовёт `restored` каждого подписчика; отказ биржи получает
  открывший подписку, запись удаляется — тесты «обрыв — `restored` у всех подписчиков соединения» и «после отказа
  следующий подписчик подписывает топик снова»
- [x] 1.6 Регистрация `BybitStreams` singleton'ом в `InfrastructureRegistrar` — проверка разрешения сервисов
  `WorkerHost` зелёная
- [x] 1.7 Обновить описание `IExchangeStreams` в `docs/conventions.md` (потоки общие на процесс) — документ обновлён
