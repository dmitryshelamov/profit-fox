# Spec Delta

## ADDED Requirements

### Requirement: Подсказка меток с весами

Подсказка над метками идеи SHALL показывать балл идеи по её стороне, затем метки с ненулевым весом по стороне идеи — по
одной в строке с их вкладом, сначала положительные по убыванию, потом отрицательные, — и одной строкой метки без веса с
их числом. Вклады SHALL браться из текущих весов меток, и их сумма SHALL равняться баллу идеи. Подсказку MUST NOT
обрезать рамка таблицы.

#### Scenario: Лонг с весами

- **WHEN** у идеи-лонга с баллом `+1` метки «цена ↓ 4h» (вес лонга `+1`), «↓ BTC 1h» (`−1`), «OI ↓ 4h» (`+1`) и
  «волат.↑ 15m» (`0`)
- **THEN** подсказка показывает «Балл лонга +1», строки «цена ↓ 4h +1», «OI ↓ 4h +1», «↓ BTC 1h −1» в этом порядке и
  строку «без веса (1): волат.↑ 15m»

#### Scenario: Шорт с теми же метками

- **WHEN** у идеи-шорта те же метки, а веса шорта у них `−1`, `+1`, `0` и `0`
- **THEN** подсказка показывает «Балл шорта 0», строки «↓ BTC 1h +1» и «цена ↓ 4h −1» и строку без веса с двумя метками

#### Scenario: Все метки без веса

- **WHEN** у идеи три метки, и у всех вес по её стороне `0`
- **THEN** подсказка показывает балл `0` и только строку «без веса (3)» со всеми тремя метками

#### Scenario: Последняя строка таблицы

- **WHEN** наводят на метки идеи в последней строке таблицы
- **THEN** подсказка видна целиком, а не обрезана рамкой таблицы
