# Proposal

## Why

У идеи бывает 15–20 меток, а подсказка над значками показывает их одной строкой через запятую. По ней не видно, откуда
взялся балл идеи: какие метки дали плюс, какие минус, а какие ничего. Владелец 2026-11-28 по снимку такой подсказки:
«давай еще и хинт переделаем», вариант — «Столбиком с весами».

## What Changes

- Подсказка над метками идеи — всплывающий блок: вверху балл идеи по её стороне, ниже метки с ненулевым весом по одной
  в строке с их вкладом (сначала плюсы по убыванию, потом минусы), внизу одной строкой метки без веса с их числом.
- Вклад метки — её вес по стороне идеи из текущих весов «Скоринга»; сумма вкладов равна баллу идеи.
- Подсказка рисуется поверх страницы и не обрезается рамкой таблицы, которая теперь прокручивается по ширине.

Чего нет: правки весов из подсказки; меток и балла вне списков идей.
