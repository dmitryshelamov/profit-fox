# Tasks

Тесты бэкенда запускаются из `backend/`: `dotnet test ProfitFox.slnx`; фронтенда — из `frontend/`: `npm test`, `npm run
typecheck`, `npm run lint`, `npm run format:check`, `npm run build`. Каждая задача начинается с теста, который без неё
падает, и каждая группа заканчивается зелёным прогоном всех тестов своей части.

Ожидания не правятся ни в одной задаче: `EngineVersionTests` с `Fixtures/EngineVersions.json`, `H0001ParityTests`,
`H0001StrategyParityTests`, `SignalNodeParityTests`, `OutcomeParityTests`, `PreviewParityTests`, `CycleRunTests`,
`PositionRunTests`, `PairPositionTests`, `PairOrdersTests`. `EngineVersion.Number` остаётся `3`. Если задача требует
иного — остановиться и записать это в «Открыто после применения».

Порядок групп — порядок работы. Слои и папки — по README, «Слои». Макеты — `mockups/`; три отличия от них названы в
`proposal.md`.

## Открыто после применения

Сюда записывается всё, что при применении разошлось с design.md.

- **1.2, несинхронные спеки.** На 2026-11-22 `origin/release/0.1.0` (`ba00e19`, слияние `feat/add-strategy-backtest`)
  не содержит `openspec/changes/archive/*-add-strategy-backtest`: изменение `add-strategy-backtest` не заархивировано.
  Ветка не переносилась. `openspec validate add-ideas-and-market --strict` (CLI 2.1.0) проходит, но печатает `INFO`:
  `strategy-backtest/spec.md: Archive would refuse this delta: ... target spec does not exist`. Проверка шла на
  несинхронных спеках; перед архивом её повторить после архива `add-strategy-backtest`.

- **2.2, ответ поддельного сервиса на `4h`.** Поддельный сервис собирает свечу любого интервала из своих минут (цены
  минуты, сумма объёмов; минуты часа `08:00` без сделок), но свеча `4h` отдаётся как прежде — объём одной минуты, свеча
  `08:00` без сделок: суммирование из минут дало бы свече `08:00` сделки часов `09:00–11:59` и сдвинуло бы ожидания
  прежних тестов, которые задача велит не менять.
- **2.4, имя теста.** Задача называет `CliAppTests`; тесты CLI в репозитории — `Tests.Integration/Cli/CliTests.cs`, новые
  сценарии записаны туда.
- **2.6, проверка на стенде.** Сервис данных недоступен из облака, поэтому команда README с `--timeframe 15m` проверена
  на тестовом стенде с поддельным сервисом данных (`CliTests`, случаи `5m` и `15m`), а не на dev-стенде Мака.
