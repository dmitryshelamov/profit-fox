# Spec Delta

## ADDED Requirements

### Requirement: Свечи названной пары

Прогон и предпросмотр графа с узлом `pair-candle` SHALL читать свечи таймфрейма названной пары за ту же историю и по тем
же правилам, что свечи сигнала, один раз на прогон, а не на каждую пару, и включать прочитанное в хэш данных. Свеча
названной пары вне её покрытия SHALL считаться отсутствующей. Названная пара, которой нет в наборе пар, MUST отклонять
предпросмотр и постановку прогона с ошибкой по узлу.

#### Scenario: Одно чтение на прогон

- **WHEN** стратегию с узлом `pair-candle` и `symbol` = `BTCUSDT` прогоняют по 831 паре на `4h`
- **THEN** свечи `4h` пары `BTCUSDT` для узла прочитаны один раз

#### Scenario: Хэш данных

- **WHEN** тот же прогон повторяют после того, как история `BTCUSDT` изменилась
- **THEN** хэш данных прогона другой

#### Scenario: Дыра у названной пары

- **WHEN** свеча `BTCUSDT` с нужным временем открытия лежит вне покрытия
- **THEN** узел на этой свече выдаёт отсутствующие значения

#### Scenario: Неизвестная пара

- **WHEN** ставят прогон стратегии, у которой `symbol` узла `pair-candle` равен `NOSUCHUSDT`
- **THEN** прогон не поставлен, и ответ несёт ошибку по этому узлу
