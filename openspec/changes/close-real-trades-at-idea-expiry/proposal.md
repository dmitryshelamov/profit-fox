# Proposal

## Why

Обещание сделки по идее (ожидание в R, значок, вероятность) посчитано по случаям, которые кончаются стопом, целью или
сроком жизни идеи. Учебная сделка закрывается по сроку идеи, а сделка с деньгами нет: после конца идеи она живёт вне
статистики, по которой её взяли. Так PIEVERSEUSDT держится больше суток после конца своей идеи. Колонка «До конца идеи»
показывает срок идеи, но не говорит, что будет со сделкой.

## What Changes

- Сделка с деньгами, ручная и автомата, закрывается по рынку в момент конца своей идеи (вход идеи + срок жизни её
  правила выхода). Закрывает торговый Worker по своим часам, как он уже снимает вход «Отката» по сроку входа. Сделка
  становится «Закрыта по сроку».
- Сделка, которая к концу идеи ещё ждёт входа, снимает вход и становится «Отменена».
- Момент конца идеи хранится на сделке. Если идея вошла позже, чем создана сделка, сканер дописывает его, когда идея
  входит.
- Новая настройка «Закрывать сделку по сроку идеи», по умолчанию включена. Worker смотрит на неё в момент конца идеи,
  так что она действует и на уже открытые сделки.
- Журнал отдаёт, закроется ли сделка сама по сроку идеи. Колонка «До конца идеи» показывает остаток и «закроется
  09.11 18:00»; при выключенной настройке — только остаток; у сделки, пережившей идею, — «идея закрыта».
- Сделки, чья идея закрылась до выкатки, не трогаются: выкатка не отправляет ни одного ордера.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `idea-trades`: настройка «Закрывать сделку по сроку идеи»; закрытие сделки с деньгами по сроку идеи.
- `idea-trades-journal`: у сделки в работе признак, что она закроется сама по сроку идеи.
- `idea-trades-interface`: колонка «До конца идеи» с моментом автозакрытия; переключатель на экране настроек.

## Impact

- Backend: `IdeaTrade` (момент конца идеи, создание из активной идеи), `IdeaTradeSession` (пробуждение и закрытие по
  сроку, роль ордера закрытия по сроку, сворачивание «Закрыта по сроку»), `IdeaRepository.SaveAsync` (дописать момент
  на сделки вошедшей идеи), `IdeaTradingSettings` и её API, `GetIdeaJournalQueryHandler`, `IdeaTradeResponse`.
- БД: миграция — `idea_trades.idea_ends_at` с заполнением для открытых сделок с активной идеей,
  `idea_trading_settings.close_at_idea_expiry` (по умолчанию `true`), роль ордера `expiry` в
  `CK_idea_trade_orders_role`.
- Frontend: переключатель в `SettingsPanel`, текст колонки в `idea-trades/model/journal.ts`, перегенерированный
  `schema.d.ts`, e2e.
- Реальные деньги: после выкатки Worker сам закрывает сделки с деньгами по рынку. Учебные сделки и сканер идей не
  меняются.
