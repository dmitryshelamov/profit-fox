## MODIFIED Requirements

### Requirement: Настройки торговли идеями

API SHALL хранить одни настройки торговли идеями: `GET` и `PUT /api/idea-trading/settings`. В них:

- аккаунт биржи по умолчанию;
- сумма на сделку в USDT;
- «Не больше суммы на сделку» в USDT;
- «Не больше открытых сделок»;
- «Не больше общего риска» в USDT;
- минимальный R:R после комиссий;
- «Закрывать сделку по сроку идеи».

Без сохранённых настроек SHALL отдаваться: аккаунта нет, сумма на сделку `20`, «Не больше суммы» `200`, сделок `5`,
общий риск `5`, R:R `1.5`, закрытие по сроку идеи включено. Неизвестный аккаунт, сумма на сделку, «Не больше суммы» или
общий риск не больше нуля, число сделок меньше 1 и R:R меньше нуля MUST давать ошибку валидации 400 по полю. Уже
сохранённые настройки SHALL получить сумму на сделку `20` и включённое закрытие по сроку идеи, остальные их значения не
меняются.

#### Scenario: Настройки по умолчанию

- **WHEN** владелец ни разу не сохранял настройки
- **THEN** API отдаёт сумму на сделку `20`, «Не больше суммы» `200`, сделок `5`, общий риск `5`, R:R `1.5`, включённое
  закрытие по сроку идеи и не отдаёт аккаунт

#### Scenario: Риск ноль

- **WHEN** владелец сохраняет «Не больше общего риска» `0`
- **THEN** API отвечает ошибкой валидации по полю общего риска, настройки не меняются

#### Scenario: Сумма ноль

- **WHEN** владелец сохраняет сумму на сделку `0`
- **THEN** API отвечает ошибкой валидации по полю суммы, настройки не меняются

#### Scenario: Закрытие по сроку после выкатки

- **WHEN** настройки были сохранены до выкатки
- **THEN** после выкатки закрытие по сроку идеи в них включено

## ADDED Requirements

### Requirement: Закрытие сделки по сроку идеи

Сделка с деньгами, ручная и автомата, SHALL хранить момент конца своей идеи: вход идеи плюс срок жизни её правила
выхода. Когда он наступил и закрытие по сроку идеи включено, Worker SHALL закрыть открытую сделку по рынку, как
«Закрыть по рынку», и она SHALL стать «Закрыта по сроку»; сделка, что ждёт входа, SHALL снять вход. Момент MUST NOT
зависеть от сканера.

#### Scenario: Идея кончилась

- **WHEN** идея 1h со сроком 24 свечи вошла в 10:00, а сделка long `0.47` по ней открыта
- **THEN** завтра в 10:00 Worker продаёт `0.47` по рынку, снимает стоп и цель, и сделка «Закрыта по сроку» с
  результатом в USDT и R

#### Scenario: Поздний ручной вход

- **WHEN** идея 1h со сроком 24 свечи вошла в 10:00, а владелец вошёл по ней в 13:00
- **THEN** сделка закрывается завтра в 10:00, вместе с идеей

#### Scenario: Сканер отстал

- **WHEN** момент конца идеи наступил, а сканер ещё не дошёл до последней минуты идеи
- **THEN** Worker всё равно закрывает сделку в этот момент

#### Scenario: Идея вошла после сделки

- **WHEN** автомат взял рыночную идею в минуту, когда она сработала, а идея вошла на открытии следующей минуты
- **THEN** у сделки появляется момент конца идеи, когда сканер записывает вход идеи, и сделка закрывается в этот момент

#### Scenario: Вход не исполнился к концу идеи

- **WHEN** к концу идеи лимитка сделки не исполнилась
- **THEN** Worker снимает вход, и сделка «Отменена»

#### Scenario: Цель раньше срока

- **WHEN** сделка закрылась по цели за час до конца идеи
- **THEN** она «Закрыта по цели», и в момент конца идеи ничего не отправляется

#### Scenario: Закрытие отклонено

- **WHEN** Bybit отклонил рыночное закрытие по сроку
- **THEN** сделка остаётся «Открыта», её стоп и цель стоят, причина показана владельцу, и закрыть можно вручную

### Requirement: Выключенное закрытие по сроку

Когда закрытие по сроку идеи выключено, Worker MUST NOT закрывать сделки по сроку идеи. Включение SHALL закрыть в
течение минуты открытые сделки, чей момент конца идеи уже прошёл.

#### Scenario: Выключено

- **WHEN** закрытие по сроку идеи выключено, и момент конца идеи открытой сделки наступил
- **THEN** сделка остаётся «Открыта»

#### Scenario: Включили после срока

- **WHEN** момент конца идеи сделки прошёл, пока закрытие было выключено, и владелец включает его
- **THEN** в течение минуты Worker закрывает сделку по рынку, и она «Закрыта по сроку»

### Requirement: Сделки, пережившие идею до выкатки

Сделка, чья идея закрылась до выкатки закрытия по сроку, MUST NOT закрываться по сроку: у неё нет момента конца идеи.
Открытая сделка, чья идея при выкатке ещё активна, SHALL получить момент конца идеи и закрыться в него.

#### Scenario: Идея закрылась до выкатки

- **WHEN** идея открытой сделки PIEVERSEUSDT истекла до выкатки
- **THEN** после выкатки Worker не отправляет по ней ордеров, и сделка открыта, пока её не закроют стоп, цель или
  владелец

#### Scenario: Идея активна при выкатке

- **WHEN** при выкатке идея открытой сделки активна и кончается через 3 часа
- **THEN** через 3 часа сделка закрывается по рынку и становится «Закрыта по сроку»
