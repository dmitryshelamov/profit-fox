# Tasks

Тесты бэкенда запускаются из `backend/`: `dotnet test ProfitFox.slnx`; фронтенда — из `frontend/`: `npm test`, `npm run
typecheck`, `npm run lint`, `npm run format:check`, `npm run build`. Каждая задача начинается с теста, который без неё
падает, и каждая группа заканчивается зелёным прогоном всех тестов своей части.

Ожидания не правятся, кроме тех, что прямо говорят о целом весе или целом балле: сценарии «Дробный вес», «Вес вне
диапазона», «Не число» и тесты выбора веса `−3…+3` на «Скоринге». Движок, узлы, `EngineVersion` не меняются. Если
задача требует иного — остановиться и записать это в раздел «Открыто после применения» в конце этого файла.

Слои и папки — по README, «Слои». Решения — `design.md`, номера в скобках.
