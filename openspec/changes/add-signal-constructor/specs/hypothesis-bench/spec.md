# Spec Delta

## MODIFIED Requirements

### Requirement: Чистое дерево

Прогон с вердиктом SHALL идти только на коммите без незакоммиченных изменений в репозитории, кроме журнала и отчётов,
которые пишет сам стенд, и файлов сигналов в `bench/signals/`; иначе MUST отклоняться до чтения истории. Сигналы в
прогоне не участвуют: гипотеза хранит свою копию графа сигнала.

#### Scenario: Незакоммиченная правка

- **WHEN** в рабочем дереве изменён файл узла
- **THEN** прогон отклоняется с ошибкой «незакоммиченные изменения»

#### Scenario: Журнал после прошлого прогона

- **WHEN** в рабочем дереве не закоммичены только `bench/ledger.jsonl` и новый отчёт прошлого прогона
- **THEN** прогон идёт

#### Scenario: Несохранённый в git сигнал

- **WHEN** в рабочем дереве не закоммичены только новый `bench/signals/funding-high.json` и правка
  `bench/signals/price-drop.json`
- **THEN** прогон идёт

#### Scenario: Правка гипотезы рядом с сигналом

- **WHEN** в рабочем дереве не закоммичены `bench/signals/funding-high.json` и `bench/hypotheses/H0002-x/hypothesis.json`
- **THEN** прогон отклоняется с ошибкой «незакоммиченные изменения» по `hypothesis.json`
