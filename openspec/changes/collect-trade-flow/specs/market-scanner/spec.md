# Spec Delta

## MODIFIED Requirements

### Requirement: Сканер — отдельный процесс

Данные рынка SHALL собирать только процесс сканера, отдельный от API и Worker'а; поток сделок (минутные суммы покупок и
продаж) собирает отдельный процесс сборщика (возможность `trade-flow`). Сканер MUST NOT выставлять ордера и MUST NOT
читать ключи аккаунтов: он обращается только к публичным данным Bybit. Сканер MUST NOT менять схему базы: миграции
выполняет API. Пока сканер не запущен, данные рынка SHALL оставаться прежними.

#### Scenario: Сканер не запущен

- **WHEN** API и Worker работают, а процесс сканера не запущен
- **THEN** новые минутные свечи рынка не сохраняются, снимок рынка не обновляется, остальная работа идёт как раньше

#### Scenario: Падение сканера не трогает ботов

- **WHEN** у запущенного бота торгующий Worker ведёт сделки, и процесс сканера падает
- **THEN** бот продолжает торговать, его статус и ордера не меняются

#### Scenario: Поток сделок без сканера

- **WHEN** сборщик потока сделок работает, а сканер остановлен
- **THEN** минуты потока сделок пар, которые были в списке сканера, продолжают записываться
