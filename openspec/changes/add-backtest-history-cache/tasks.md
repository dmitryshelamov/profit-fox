# Tasks

Тесты бэкенда запускаются из `backend/`: `dotnet test ProfitFox.slnx`. Фронтенд изменение не трогает. Каждая задача
начинается с теста, который без неё падает, и каждая группа заканчивается зелёным прогоном всех тестов бэкенда.

Ожидания не правятся ни в одной задаче: `EngineVersionTests` с `Fixtures/EngineVersions.json`, тесты паритета H0001,
прежние тесты прогона и предпросмотра. `EngineVersion.Number` остаётся `4`. Если задача требует иного — остановиться и
записать это в раздел «Открыто после применения» в конце этого файла.

Порядок групп — порядок работы. Слои и папки — по README, «Слои». Решения — `design.md`, номера в скобках. Группы 1–6
делает сессия применения; сервиса данных из облака не видно, поэтому группа 7 — замеры основной сессии на стенде Мака.
