# Spec Delta

## MODIFIED Requirements

### Requirement: Источник истории

Стенд SHALL читать свечи, выплаты фандинга и точки OI потоком `History` сервиса данных по gRPC. Точки OI SHALL читаться
только для графов, в которых есть узел «OI». Адрес сервиса SHALL задаваться настройкой. Стенд MUST NOT читать базу
сервиса напрямую.

#### Scenario: Сервис недоступен

- **WHEN** сервис данных не отвечает
- **THEN** прогон завершается состоянием `failed` с ошибкой «история недоступна» и результата не имеет

#### Scenario: Граф без узла OI

- **WHEN** прогоняют стратегию, в графе которой и в графах её сигналов нет узла «OI»
- **THEN** точки OI у сервиса данных не запрашиваются

#### Scenario: Граф с узлом OI

- **WHEN** прогоняют стратегию с узлом «OI» на `BTCUSDT`
- **THEN** точки OI `BTCUSDT` за период прогона прочитаны и входят в хэш прочитанного
