# Tasks

Новая логика — строго red → green → refactor (см. `CLAUDE.md`): сначала падающий тест, потом минимальный код. Это
относится и к TypeScript: модули `model` и `drafts` пишутся только под падающий тест Vitest. Задача закрыта, только
когда проходят build, тесты и `dotnet format --verify-no-changes`, а с группы 2 — ещё lint, `format:check`, typecheck,
тесты и сборка фронтенда.
