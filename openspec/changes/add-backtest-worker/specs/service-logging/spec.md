# Spec Delta

## ADDED Requirements

### Requirement: Лог Worker'а

Worker SHALL писать лог по тем же правилам, что API: только в стандартный вывод, JSON вне Development, читаемый
текст в Development, ошибка запуска — уровнем `Fatal`. Сбой одной единицы работы SHALL писаться уровнем `Error` с
её идентификатором и MUST NOT останавливать Worker.

#### Scenario: Сбой куска в Production

- **WHEN** расчёт куска бэктеста в Worker'е в среде Production завершается непредвиденным исключением
- **THEN** в стандартный вывод попадает одна JSON-строка уровня `Error` с идентификатором бэктеста и текстом
  исключения, а Worker продолжает брать работу

#### Scenario: Ошибка запуска Worker'а

- **WHEN** Worker запускается с неверными настройками аренды
- **THEN** в логе есть событие уровня `Fatal` с текстом исключения, после чего процесс завершается с ненулевым кодом
