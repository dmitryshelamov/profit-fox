# Tasks

Тесты бэкенда запускаются из `backend/`: `dotnet test ProfitFox.slnx`; фронтенда — из `frontend/`: `npm test`, `npm run
typecheck`, `npm run lint`, `npm run format:check`, `npm run build`. Каждая задача начинается с теста, который без неё
падает, и каждая группа заканчивается зелёным прогоном всех тестов своей части.

Ожидания не правятся ни в одной задаче: `EngineVersionTests` с `Fixtures/EngineVersions.json`, тесты паритета H0001,
прежние тесты списков идей и рынка. Если задача требует иного — остановиться и записать это в раздел «Открыто после
применения» в конце этого файла.

Порядок групп — порядок работы. Слои и папки — по README, «Слои». Решения — `design.md`, номера в скобках. Ветка —
`feat/add-instrument-kind-filter` от `feat/add-setup-strategies`.
