# Tasks

Новая логика идёт строго по TDD: красный тест, минимальный код, рефакторинг. Ссылки «решение N» — на design.md. Эталонные
числа — в сценариях спеки `trade-ideas`.

## 1. Домен: скученные суммы

- [x] 1.1 `ClusteredSums` (решение 1):
  - добавление случая с часом, итогом и исходом;
  - G, Σn_g², Σn_g·S_g, ΣS_g², Σn_g·T_g, ΣT_g² по словарю групп;
  - удаление случая обратно добавлению.

  Готово, когда `ClusteredSumsTests` видят, что добавить и удалить случай — это прежние суммы, а суммы двух случаев одного
  часа отличаются от сумм двух разных часов.
- [x] 1.2 Собственные числа по скученным суммам: V = max(V_r, s²/n), V = s² при G < 2, n_eff и Wilson по n_eff. Готово,
  когда тесты на эталонах зелёные:
  - 20 часов по 20 одинаковых итогов, 8 × +2 R и 12 × −1 R → +0.2 R с интервалом −0.461…+0.861 R и доля 40 % около
    22–62 %;
  - 400 случаев в разные часы, +0.12 R и s 1.2 → +0.002…+0.238 R;
  - суммы групп с разбросом меньше независимого дают независимый интервал.

## 2. Домен: модель корзины

- [x] 2.1 `BucketModel`, ожидание (решение 2): τ² по DerSimonian–Laird по корзинам родителя от 30 случаев, τ² = 0 при
  k < 2, B, ожидание и интервал модели, `ParentWeight`. Готово, когда тесты при τ = 0.1 R и родителе 9 000 × −0.20 R
  (s 1.2) дают:
  - 35 × +0.30 R → −0.10 R, интервал −0.279…+0.075 R, ≈;
  - 5 000 × +0.10 R → +0.09 R, интервал +0.059…+0.124 R, ▲;
  - корзины без разброса сверх случайного → числа родителя.
- [x] 2.2 Корзина меньше 30 своих случаев: разброс от родителя, `FewOwnCases`. Родитель меньше 30 — «мало данных» с
  собственным ожиданием. Готово, когда тесты видят:
  - 12 × +0.50 R → −0.15 R, интервал −0.336…+0.044 R, «мало своих данных»;
  - родитель из 25 случаев → «мало данных» без вероятности и значка.
- [x] 2.3 Вероятность модели тем же подтягиванием на доле «Цель», с интервалом в [0, 1]; родитель подтягивается к
  категории. Готово, когда тесты видят долю модели между долями корзины и родителя, интервал не выходит за 0 и 1, а
  числа родителя подтянуты к категории.
- [x] 2.4 `BucketStatistics` (решение 3): собственные числа, `ParentWeight`, `FewOwnCases`; `Badge` по интервалу
  модели. Готово, когда тест «Значок по модели» даёт ≈ при собственном интервале выше нуля, а `dotnet build` проходит.
