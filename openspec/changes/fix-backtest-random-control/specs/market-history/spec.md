# Spec Delta

## MODIFIED Requirements

### Requirement: Минутные свечи в окнах сделок

Прогон SHALL просить минутные свечи только там, где они ему нужны. У стратегии вида «категория идей» — в неделях, где у
пары есть заявка хотя бы одного набора прогона или случайный вход, плюс наибольший срок цикла этой недели. У стратегии
вида «для бота» — по всей истории прогона. Наборы одного прогона SHALL считаться на одной прочитанной истории пары:
история пары MUST NOT читаться заново для каждого набора.

#### Scenario: Неделя без событий

- **WHEN** у пары ни у одного набора прогона нет в неделе ни заявок, ни случайных входов
- **THEN** прогон не просит минутные свечи этой пары за эту неделю, и процесс без папки кэша не читает их у сервиса
  данных

#### Scenario: Шесть наборов на одной истории

- **WHEN** прогон из шести наборов на одном таймфрейме считает пару
- **THEN** минутные свечи каждой недели этой пары прочитаны один раз, а свечи таймфрейма — не больше двух раз: при
  поиске заявок и при расчёте сделок

#### Scenario: Неделя со случайным входом

- **WHEN** у пары нет заявок в неделе, она стоит в контрольной группе этой недели, и у другой пары прогона в эту неделю
  есть заявка
- **THEN** минутные свечи пары за эту неделю прочитаны, плюс наибольший срок цикла её случайных входов
