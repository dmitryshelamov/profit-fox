# 0009. Правила вердикта: порог по числу попыток, мощность вслепую, границы периодов

Дата: 2026-11-16. Решил агент по поручению владельца («делай полностью бенч как считаешь нужным»). Уточняет части 2–4
плана стенда, где он не называл чисел.

Перенесено из ADR 0011 репозитория `profit-fox-bench` без изменения решения.

## Обстоятельства

План задаёт вердикт словами: t ≥ 3, тот же знак в обеих половинах, мощность до прогона, число попыток из журнала. Чтобы
стенд считал одинаково от гипотезы к гипотезе, нужны числа и порядок шагов.

## Решение

- **Единица доказательства** — блок времени: среднее по всем событиям блока (все пары вместе) разницы «исход события минус
  средний исход его случайных входов». Событие учитывается, если его сделка в покрытии и у него не меньше двух
  действующих случайных входов.
- **Нужный t** = 3 при первой попытке и растёт с числом попыток N: односторонний хвост t = 3 (0,135 %) делится на N
  (Бонферрони). N = 10 → 3,65; N = 100 → 4,2. N — число разных гипотез с вердиктом «прошла» или «отвергнута» в этом
  периоде по журналу, включая текущую. Прогоны «данных мало», «заглядывание» и упавшие попыткой не считаются.
- **Знак**: среднее за блок положительно (событие лучше случайного входа) и в первой, и во второй половине блоков по
  времени.
- **Мощность вслепую**: до чтения исходов событий стенд берёт у каждого события один случайный вход как «ложное событие»
  минус среднее остальных, считает разброс средних за блок и мощность найти наименьший эффект гипотезы (по умолчанию
  0,1 R) при нужном t. Нужны мощность ≥ 0,8 и не меньше 20 блоков; иначе вердикт «данных мало», и исходы событий не
  читаются. Такой прогон не делает разведку окончательной и не открывает отложенный период.
- **Границы периода**: событие входит в период, если его сделка целиком, со сроком, укладывается в период; случайные
  входы берутся оттуда же. Исполнитель получает данные только до конца периода (ADR 0004).
- **Случайные входы** — на закрытиях свечей таймфрейма гипотезы в том же блоке, где у пары не было события, с
  возвращением; зерно — от хэша гипотезы, поэтому прогон повторяем.
- **Исполнение**, которое план не уточнял: цель — лимитная заявка, исполняется по цене цели без проскальзывания, в том
  числе при гэпе через неё; выход по сроку — по закрытию последней минуты со сделками; фандинг платится за выплаты в
  моменты `вход < t ≤ выход` по цене минуты перед выплатой; минута без сделок на входе — вход по открытию следующей
  минуты со сделками.

## Почему

- Бонферрони проще и строже соседей; при десятках гипотез порог остаётся достижимым.
- Мощность вслепую не даёт подглядеть в исходы и бросить гипотезу «на полпути», а затем перезапустить её на других
  данных.
- Сделка, заходящая в следующий период, пропускала бы его цены в текущий.

## Следствия

- Гипотеза с редкими событиями или малым эффектом на коротком периоде получает «данных мало», а не «отвергнута».
- Отложенный период (около 26 недельных блоков) по мощности подходит только для заметных эффектов; если мощности не
  хватает, он для этой гипотезы не открывается, и что делать с ней дальше, решает владелец.
