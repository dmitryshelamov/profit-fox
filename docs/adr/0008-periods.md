# 0008. Отложенный период — последние 6 месяцев истории

Дата: 2026-11-16. Решил владелец, одобрив план стенда.

Перенесено из ADR 0007 репозитория `profit-fox-bench` без изменения решения.

## Обстоятельства

Стенд делит историю на периоды, чтобы гипотеза, найденная на одной части, проверялась на части, которую она не видела.
История догружается до трёх лет (ADR 0007).

## Решение

Периоды заданы датами (UTC) и не сдвигаются:

- разведка — от начала данных по 2026-05-15 включительно;
- отложенный период — с 2026-05-16 по 2026-11-15 включительно; открывается один раз на гипотезу и только после того, как
  она прошла разведку;
- новые данные — с 2026-11-16; на них идёт проверка на новых данных.

## Почему

- Последние месяцы ближе всего к рынку, на котором правило будет торговать.
- Полгода — около 26 недельных блоков: хватает, чтобы проверить знак эффекта, найденного в разведке, и разведке
  остаётся остальная история.
- Сплошной кусок в конце не перемешивается с разведкой: соседние блоки зависят друг от друга, а отложенные блоки внутри
  разведки пропускали бы в неё тот же режим рынка.

## Отвергнуто

- Отложенные блоки вперемешку с разведкой: см. выше.
- Отложенный год: сокращает разведку, пока история ещё догружается.

## Следствия

- Даты одни для всех гипотез, в том числе записанных позже; новые данные копятся с 2026-11-16.
- Пока история догружается, разведка растёт только в прошлое.
- Открытие отложенного периода записывается в журнал прогонов; повторное открытие для той же гипотезы стенд отклоняет.
