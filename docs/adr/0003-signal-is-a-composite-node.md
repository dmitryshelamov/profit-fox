# 0003. Сигнал — составной узел графа стратегии

Дата: 2026-11-17. Решил владелец (у бота конструктор стратегий, как в старом проекте). Заменяет ADR 0008 репозитория
`profit-fox-bench` («событие — функция на Python»).

## Обстоятельства

У бота будет конструктор стратегий: граф из узлов библиотеки, как в спецификации `strategy-graph` проекта
`profit-fox-v2`. Стенду нужен способ записать сигнал так, чтобы бот исполнил его без перевода.

## Решение

- Сигнал — составной узел графа с одним логическим выходом «вход сейчас».
- Гипотеза — файл `bench/hypotheses/H<NNNN>-<name>/hypothesis.json`: сигнал и план сделки (сторона, срок, стоп и цель).
- Исполнитель Engine считает граф по закрытым свечам — свеча за свечой, по всем парам в один момент. Стенд и бот
  используют один исполнитель.
- Сигнал, прошедший стенд, ставится в стратегию конструктора как есть.

## Почему

- Бот исполняет тот же файл, который прошёл стенд.
- Узел видит только закрытые свечи, поэтому заглянуть в будущее нельзя по устройству; проверка заглядывания пишется
  один раз тестами узлов, а не гоняется на каждой гипотезе.
- Перебор параметров — замена чисел в графе; параметры с границами в графе уже есть.

## Отвергнуто

- Отдельный JSON условий для стенда: второй формат рядом с графом конструктора.
- Векторный расчёт сигнала на стенде: вторая реализация, которую пришлось бы сверять с исполнителем.

## Следствия

- Идея, которую нельзя собрать из имеющихся узлов, начинается с нового узла и его тестов.
- В графе нужны узлы, которых не было в старом проекте: по всему рынку (доля пар, ранг пары), фандинг, открытый
  интерес, лонг/шорт.
