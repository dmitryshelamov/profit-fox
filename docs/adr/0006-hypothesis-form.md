# 0006. Форма гипотез: «событие → сделка», корзина — частный случай

Дата: 2026-11-16. Решил агент по поручению владельца («ты в роли торгового эксперта, выбирай»).

Перенесено из ADR 0001 репозитория `profit-fox-bench` без изменения решения.

## Обстоятельства

Почти все проверки старого проекта имели форму «событие на паре → сделка со стопом, целью и сроком». Две нити, где
результат до издержек был выше нуля, устроены иначе: «шорт отстающих» — корзина пар по расписанию без стопов, шорты при
высоком фандинге — удержание позиции. Ядро под одну форму не считает другую.

## Решение

Первая версия стенда считает форму «событие → сделка». Ядро строится так, чтобы корзина была её частным случаем:

- стоп и цель в плане сделки необязательны;
- условие события может сравнивать пары между собой;
- исход считается в процентах суммы сделки всегда и в R, когда есть стоп.

Корзины по расписанию — второй шаг, без переделки ядра.

## Почему

- На форме «событие → сделка» стенд сверяется с известными результатами старого проекта; для корзин такого контроля нет.
- Идеи владельца приходят в этой форме.
- Корзина раскладывается на те же части: попадание пары в корзину — событие, удержание — сделка по сроку, «корзина минус
  рынок» — сравнение со случайным входом в том же блоке времени.

## Следствия

- «Шорт отстающих» до второго шага считается отдельным скриптом на открытых данных Bybit, как раньше.
- Гипотезы смещаются с 5 и 15 минут на диапазон от 4 часов до недели: издержки в R падают как 1/√T.
